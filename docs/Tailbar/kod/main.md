# `main.py` — програмын эхлэл

← [Буцах](../README.md)

## Юу хийдэг
Програм (`AjliinButeemj.exe` эсвэл `python main.py`) **эндээс эхэлнэ**. Командын сонголтыг уншаад аль горимоор ажиллахаа
сонгоно: цонхтой, цонхгүй (tray), админ тохиргоо, өөрийгөө шалгах, тайлан гэх мэт. Мөн програм **нэг л хувь** ажиллахыг хянана
(хоёр хувь ажиллавал цаг давхар тоологдоно).

## Командын сонголтууд
| Сонголт | Юу болох вэ | Хэн хэрэглэдэг |
|---|---|---|
| *(сонголтгүй)* | Цонхтой нээгдэнэ | Ажилтан давхар товшиход |
| `--background` | Цонхгүй, зөвхөн tray дүрс | Компьютер асахад автоматаар (`system.set_autostart`) |
| `--admin-setup` | Энэ компьютерийг админых болгох цонх | Админ, нэг удаа ([admin_setup.md](worktracker/admin_setup.md)) |
| `--admin-setup-system ФАЙЛ` | (нууц) UAC-аар админ эрхтэй дахин эхэлсэн хэсэг | `admin_setup` өөрөө дууддаг |
| `--selftest` | Камер нээхгүйгээр бүх модулийг шалгаж үр дүнг хэвлэнэ/логлоно | Суулгасны дараа, `build.py --selftest` |
| `--no-gui` | Терминал дээр ажиллана | Хөгжүүлэлт |
| `--camera-test` | Камер + царайн хүрээг харуулах цонх (юу ч хадгалахгүй) | Камер шалгах |
| `--report [ӨДӨР]` | Өдрийн HTML тайлан үүсгээд нээнэ | |
| `--send [ӨДӨР]` | Тайланг имэйл/Telegram-аар илгээнэ | |
| `--updated` | (нууц) Шинэчлэлийн дараа дахин эхлэхэд — цонхгүй эхэлнэ, хуучин процесс хаагдахыг 20 сек хүлээнэ | `updater.apply` |

## Функцууд
| Функц | Юу хийдэг |
|---|---|
| `main()` | Сонголтуудыг уншина → лог эхлүүлнэ (`system.setup_logging`) → `--admin-setup*`-ийг тохиргоо уншихаас **өмнө** шийднэ → тохиргоо (`config.load_config`) → горим сонгоно. Цонхтой горимд: нэг хувь шалгаад (`ensure_single_instance`), автоматаар эхлэхийг бүртгэнэ (`set_autostart`), `gui.run_gui(...)`. |
| `_make_client(cfg)` | `share.json`-оос админы хавтасны клиент (`ShareClient`) үүсгэнэ; байхгүй бол `None`. |
| `selftest(cfg, log_path)` | Идэвхтэй апп, идэвхгүй хугацаа, түгжээ, царай илрүүлэгч, ажилтны нэр/uid, хавтас холбогдсон эсэх, админ компьютер эсэхийг шалгаж хэвлэнэ. exe-д консол байхгүй тул лог руу бичнэ. Алдаа байвал 1 буцаана. |
| `run_headless(cfg)` | Цонхгүй (терминал) горим — нэр асууж, `App(...).run_headless()`. |

## Давхар нээх үед
Програм аль хэдийн ажиллаж байхад дахин нээвэл: `signal_running_instance()` ажиллаж буй хувь руу "show" илгээж цонхыг нь гаргаж
ирээд шинэ хувь нь хаагдана. `--background`-тэй (автомат эхлэл) бол юу ч харуулахгүй чимээгүй гарна.

## Анхаарах
- `--admin-setup` болон `--admin-setup-system`-ийг `load_config()`-оос өмнө шалгадаг — админ эрхтэй процесс ажилтны тохиргоог
  үүсгэх шаардлагагүй.
- Шинэ сонголт нэмэх бол `p.add_argument(...)`-д нэмээд `main()` дотор нэг хувь шалгахаас өмнө эсвэл хойно (горимоос хамаарч) шийднэ.
