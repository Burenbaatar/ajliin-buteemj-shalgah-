# `worktracker/presence.py` — камер ба царай илрүүлэх

← [Буцах](../../README.md)

## Юу хийдэг
Арын thread дээр камераас **секунд тутам** кадр уншиж, хүний царай байгаа эсэхийг шалгана. Мөн хуурах оролдлогыг илрүүлнэ:
камерын өмнө **зураг** тавих (царай огт хөдлөхгүй), камерыг **таглах** (кадр хар/нэг өнгө). Кадрыг зөвхөн санах ойд
шалгаад устгадаг — **зураг, бичлэг хадгалахгүй.**

## Классууд
| Нэр | Юу хийдэг |
|---|---|
| `FaceDetector` | OpenCV-ийн **YuNet** загвараар (`assets/face_detection_yunet_2023mar.onnx`) царай олно; загвар байхгүй бол хуучин Haar cascade. Хурдлахын тулд кадрыг 320 px өргөн болгож жижигрүүлнэ (`DETECT_WIDTH`). `detect(frame)` → царайнуудын `(x, y, w, h)`. |
| `Liveness` | Амьд хүн нүдээ ирмэх, амьсгалах, бага хөдлөхөд нүүрний хэсэг кадр хооронд өөрчлөгддөг. Нүүрийг 32×32 болгож гэрлийн өөрчлөлтийг арилгаад өмнөх кадртай харьцуулна. Ялгаа `MOTION_THRESHOLD` (0.05)-аас бага үргэлжилбэл `is_static()` → зураг байж магадгүй. |
| `PresenceMonitor` | Камерыг нээж арын thread-д ажиллуулна. Гаргадаг утгууд: `camera_ok`, `last_face_time`, `face_static`, `blocked`, `camera_state` (`ok` / `blocked` / `static` / `none`). |

## `PresenceMonitor`-ийн функцууд
| Функц | Юу хийдэг |
|---|---|
| `start()` | Анхны нээлтийг **main thread** дээр (macOS зөвшөөрөл), дараа нь thread эхлүүлнэ. Камер олдохгүй бол гар/хулганаар л шалгана. |
| `stop()` | Thread зогсоож камерыг суллана. |
| `set_paused(bool)` | "Зогсоох" дарахад камерыг **бүрэн хаана** (гэрэл унтарна), "Үргэлжлүүлэх"-д 10 сек хүлээлгүй шууд нээнэ. |
| `_run()` | Үндсэн давталт: зогсоосон бол камерыг хаагаад хүлээнэ; камер салсан бол 10 сек тутам дахин нээнэ; 5 удаа дараалан кадр уншиж чадахгүй бол дахин холбогдоно; кадр бүрийг `_process`-д. |
| `_process(frame)` | Таглагдсан эсэх → царай хайх → амьд эсэх. Амьд царай олдвол `last_face_time`-г шинэчилнэ. |
| `_check_blocked(gray, now)` | Кадр бараг хар (дундаж < 25, хэлбэлзэл < 12) эсвэл нэг өнгө (хэлбэлзэл < 5) **30 сек** (`camera_blocked_sec`) үргэлжилбэл `blocked`. |

## Бусад
- `_open_camera(index)` — Windows: DirectShow, macOS: AVFoundation; 640×480, буфер 1 кадр (хоцрохгүй).
- `camera_test(index)` — `--camera-test`: царайг хүрээгээр харуулдаг цонх (юу ч хадгалахгүй), Q/Esc-ээр гарна.

## Тохиргоо (админ самбараас)
| Түлхүүр | Анхдагч | |
|---|---|---|
| `liveness_enabled` | `true` | Зураг илрүүлэх эсэх |
| `liveness_static_sec` | 120 | Хэдэн сек хөдлөхгүй бол сэжигтэй |
| `camera_blocked_sec` | 30 | Хэдэн сек хар бол таглагдсан |

## Хязгаар
Дэлгэц/утсан дээрх **видео**, гарт барьж хөдөлгөж буй зургийг ялгахгүй. Бүдэг гэрэлд шуугиан ихсэх тул зураг илрэхгүй байж болно
(харин амьд хүнийг буруу тэмдэглэхгүй).
