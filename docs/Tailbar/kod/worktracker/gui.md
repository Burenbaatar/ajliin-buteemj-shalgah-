# `worktracker/gui.py` — үндсэн цонх ба tray

← [Буцах](../../README.md)

## Юу хийдэг
Ажилтны харах цорын ганц дэлгэц: ногоон/улаан/шар төлөвийн самбар, өнөөдөр ажилласан таймер, одоогийн апп, камер, админы хавтасны
холболт, өнөөдрийн аппууд, товчнууд. Мөн цагны хажуугийн **tray дүрс**. Програмын цонхтой эхлэл (`run_gui`) энд байна.

## Цонхны бүтэц (`MainWindow`)
```
┌───────────────────────────────┐
│ ● Ажиллаж байна       (ногоон)│  ← төлөв: ногоон / улаан (гарсан) / шар (зогсоосон)
│ 1:02:05  Өнөөдөр ажилласан    │
├───────────────────────────────┤
│ Ажилтан · Ажлаас гарсан ·     │
│ Одоогийн апп · Камер ·        │
│ Админы хавтас                 │
│ Өнөөдрийн аппууд (6)          │
├───────────────────────────────┤
│ [Самбар*] [⏸ Зогсоох] [Тайлан] [Илгээх*]│  * зөвхөн админд / имэйл тохируулсан үед
│ Дэлгэц бичихгүй…    Нэр солих │
│ [   Програмаас гарах   ] (улаан)│
└───────────────────────────────┘
```

## Классууд ба функцууд
| Нэр | Юу хийдэг |
|---|---|
| `Tray` | Windows: pystray дүрс (ногоон / улаан / саарал / шар дугуй), цэс: Нээх · ⏸ Зогсоох / ▶ Үргэлжлүүлэх · Самбар (админ) · Програмыг хаах. macOS: Dock дүрс. |
| `MainWindow.refresh()` | **Секунд тутам**: `tracker.snapshot()`-оос цонх, tray-г шинэчилнэ; 30 мин тутам шинэчлэл шалгана. |
| `toggle_pause()` | Зогсоох/Үргэлжлүүлэх (`tracker.set_paused`), tray мэдэгдэл. |
| `open_dashboard()` | Зөвхөн админы компьютер дээр: админ нууц үг асууж (`config.check_password`) самбар нээнэ. |
| `open_report()` | Өнөөдрийн HTML тайланг үүсгэж хөтөчид нээнэ. |
| `send_report()` | Тайланг имэйл/Telegram-аар (тохируулсан үед). |
| `change_name()` | "Нэр солих" — `config.json`-д хадгалж хавтас дахь нэрийг шинэчилнэ. |
| `hide()` | ✕ дарахад цонхыг нууна (цаг тоолсоор), анх удаа tray мэдэгдэл. |
| `on_close()` | **Програмаас гарах** / tray "Програмыг хаах": "Хаах уу?" → `app.stop()` (эцсийн JSON + Офлайн) → хаана. |
| `check_update(auto)` / `_install(info)` | Админы хавтасны `update\`-ээс шинэ хувилбар. Эхлэх үед болон цонх нуугдсан үед **асуулгүй** суулгана; цонх нээлттэй бол товч гаргана. |
| `ask_name(root)` | Анх нээхэд нэр асууна (Windows хэрэглэгчийн нэрээр бөглөсөн). |
| `ask_share(root)` | `share.json` огт олдохгүй үед л хавтасны замыг асууна (exe-д багцлагдсан бол гарахгүй). |
| `run_gui(cfg, updated, background)` | Эхлэл: tray → нэр → хавтасны клиент → `App` эхлүүлэх → `MainWindow` → (`--background` бол нуух) → шинэчлэл шалгах → Tk давталт. |

## Тогтмолууд
`TOP_N = 6` (цонхонд харуулах апп), `CAMERA_WARN` (камерын анхааруулгын текст), `PAUSED_COLOR = "#9a6700"` (шар).

## Анхаарах
- Tkinter зөвхөн main thread-ээс шинэчлэгдэх ёстой — арын ажил `uiutil.Bg.run(...)`-ээр, tray-ийн үйлдэл `bg.call_soon(...)`-ээр.
- Цонх/товч нэмэх бол `MainWindow.__init__`; секунд тутам өөрчлөгддөг зүйл бол `refresh()`.
