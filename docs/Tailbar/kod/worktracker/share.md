# `worktracker/share.py` — админы хуваалцсан хавтастай ажиллах

← [Буцах](../../README.md)

## Юу хийдэг
Админы компьютерийн хуваалцсан хавтас (`\\DESKTOP-…\AjliinButeemj`, админы компьютер дээр `C:\AjliinButeemjData`) нь
програмын **"сервер"**. Энэ файл тэр хавтсанд JSON унших/бичих, автоматаар нэвтрэх, самбарт өгөгдөл өгөх, админы үйлдлүүдийг хийнэ.
Самбар болон `cloud.py` нь `select()` / `rpc()` гэсэн хоёр л функцээр ажилладаг.

## Хавтасны бүтэц
```
company.json                     тохиргоо, хэлтэс, хүмүүсийн нэр/хэлтэс/идэвхтэй, устгасан хүмүүс   (зөвхөн админ бичнэ)
people\<uid>\profile.json        нэр, Windows хэрэглэгч, компьютер, бүртгэгдсэн огноо              (тэр ажилтан)
people\<uid>\live.json           одоогийн төлөв, апп, камер, зогсоосон эсэх, сүүлд харагдсан        (тэр ажилтан)
people\<uid>\days\<өдөр>.json    өдрийн дүн                                                        (тэр ажилтан)
```
`uid` = `<Windows хэрэглэгч>@<компьютер>` (`make_uid()`). Ажилтан бүр зөвхөн өөрийн хавтсанд бичдэг → зөрчил гарахгүй.

## Туслах функцууд
| Функц | Юу хийдэг |
|---|---|
| `make_uid()` / `default_name()` | Ажилтныг таних id / Windows хэрэглэгчийн нэр. |
| `read_json(path)` | Унших; файлыг өөр компьютер яг сольж байвал (Windows түр хориглодог) хэд дахин оролдоно. |
| `write_json(path, data)` | Түр файлд бичээд `os.replace` — хагас файл үлдэхгүй; түгжигдсэн бол 2 сек хүртэл дахин оролдоно. |
| `resolve_root(info)` | Аль замыг ашиглах: админы компьютер дээр `local_path`, бусад нь UNC зам; Mac дээр mount хийх хавтас. |
| `ensure_connected(info, root)` | Хавтас харагдахгүй бол `share.json`-ийн тусгай хэрэглэгчээр `net use` (Windows) / `mount_smbfs` (Mac). Минутад нэг л удаа. |

## `ShareClient` класс
| Функц | Юу хийдэг |
|---|---|
| `ShareClient(info, uid, name)` | `info` = `share.json`-ийн агуулга. |
| `available()` | Хавтас харагдаж байна уу (шаардлагатай бол нэвтэрч үзнэ). |
| `company()` | `company.json`-г уншина (дутуу түлхүүрүүдийг анхдагч утгаар нөхнө). |
| `select(table, columns, **filters)` | Самбарын унших хүсэлт: `wt_company`, `wt_departments`, `wt_profiles`, `wt_live`, `wt_daily` (өдрөөр шүүх `day="eq.2026-11-13"`, `gte./lte.`). Устгасан хүмүүсийг алгасна. |
| `rpc(fn, params)` | Бичих үйлдэл — доорх `_wt_*` функцуудыг нэрээр нь дуудна. |
| `set_name(name)` | Ажилтан нэрээ солибол дараагийн бичилтэд `profile.json` шинэчлэгдэнэ. |
| `is_admin` | Админ нууц үгээр самбар нээхэд `True` болно — админы үйлдлүүд үүнийг шаардана. |

## Бичих үйлдлүүд (`rpc`)
| Нэр | Хэн | Юу хийдэг |
|---|---|---|
| `wt_push` | Ажилтны програм | Өдрийн дүн + `live.json` (+ анх удаа `profile.json`). `p_live_only` бол зөвхөн live. Устгагдсан хүн бол татгалзана. |
| `wt_admin_update_user` | Админ | Нэр, хэлтэс, идэвхтэй эсэх |
| `wt_admin_save_department` / `_delete_department` / `_set_department_chat` | Админ | Хэлтэс нэмэх/засах/устгах, Telegram чат |
| `wt_admin_save_settings` | Админ | Компанийн тохиргоо |
| `wt_admin_remove_user` / `_restore_user` | Админ | **Бүрмөсөн устгах** (хавтас + түүх; `company.json`-ийн `removed`-д нэмж тэр програмыг цаашид бичүүлэхгүй) / сэргээх |
| `wt_admin_set_telegram` / `_telegram_configured` | Админ | Telegram токен — хавтсанд биш, админы компьютерийн `admin.json`-д |

## Алдаа
- `NetworkError` — хавтас олдсонгүй ("Админы хавтас олдсонгүй (админы компьютер асаалттай … эсэхийг шалгана уу)").
- `ShareError` — буруу өгөгдөл / эрхгүй үйлдэл; `.friendly` нь Монгол мессеж (`_MESSAGES`).

## Анхаарах
- Хавтасны бүтцэд шинэ түлхүүр **нэмэх** нь аюулгүй; байгааг **устгах/нэр солих** нь хуучин хувилбартай ажилтнуудыг эвдэнэ.
- Устгасныг шалгах (`_is_removed`) 30 сек кэштэй — устгасны дараа хэдэн секунд бичигдсэн үлдэгдлийг самбар өөрөө цэвэрлэнэ.
