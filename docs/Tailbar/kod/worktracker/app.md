# `worktracker/app.py` — хэсгүүдийг угсардаг цөм

← [Буцах](../../README.md)

## Юу хийдэг
Програмын бүх "хөдөлгүүрийг" нэг дор угсарч асааж, унтраана: **камер** (`PresenceMonitor`), **цаг тоологч** (`Tracker`),
**хавтас руу хуулагч** (`CloudSync`), (админд) **Telegram мэдэгдэл** (`AlertRunner`), **өдрийн тайлан илгээгч** (`ReportScheduler`).
Цонх (`gui.py`) болон терминал горим (`main.run_headless`) хоёулаа энэ `App`-ийг ашигладаг.

## `App` класс
| Функц | Юу хийдэг |
|---|---|
| `App(cfg, api=None, admin=False)` | Хадгалалт (`Storage`), камер, tracker, тайлан илгээгч үүсгэнэ. `api` (ShareClient) байвал `CloudSync` үүсгэж tracker-тэй холбоно: төлөв солигдоход `cloud.poke`, апп солигдоход `cloud.poke_live`. `admin=True` бол `AlertRunner`. Камер ачаалж чадахгүй бол програм камергүйгээр үргэлжилнэ. |
| `start()` | Камер → tracker → cloud → alerts дарааллаар асаана. **Main thread дээр** дуудах ёстой (macOS камерын зөвшөөрлийн цонх). |
| `stop()` | Эсрэг дарааллаар зогсооно. `cloud.stop()` эцсийн дүн + "Офлайн"-г хавтсанд бичнэ. Хоёр дахь удаа дуудахад юу ч хийхгүй. |
| `cloud_status()` | Цонхны "Админы хавтас" мөрийн текст ("Холбогдсон (5 сек өмнө)", "Алдаа: …"). |
| `send_today()` | "Илгээх" товч — өнөөдрийн тайланг имэйл/Telegram-аар. |
| `run_headless()` | Терминал горим: Ctrl+C хүртэл ажиллаж, төлөв өөрчлөгдөх бүрт мөр хэвлэнэ. |

## `ReportScheduler`
`config.json`-д имэйл/Telegram тохируулсан үед л ажиллана. Tracker минут тутам дууддаг: `report_time` (18:00) болсон бол
өнөөдрийн, мөн сүүлийн 7 хоногийн (`CATCHUP_DAYS`) илгээгдээгүй тайланг арын thread-д илгээнэ. Амжилтгүй бол 10 мин
(`RETRY_SEC`) хүлээгээд дахин.

## `storage_path(user_id)`
Ажилтны өгөгдлийн хавтас: `%APPDATA%\AjliinButeemj\users\<uid>\worktime\`. Нэг компьютерийг хэд хэдэн Windows хэрэглэгч
ашиглавал тус тусдаа хадгалагдана.
