# `worktracker/tracker.py` — "ажиллаж байна уу?" гэж шийддэг гол логик

← [Буцах](../../README.md)

## Юу хийдэг
Арын thread дээр **секунд тутам** камер, гар/хулгана, дэлгэцийн түгжээ, идэвхтэй аппыг харж тухайн секундийг
**ажилласан** эсвэл **гарсан** гэж ангилна, апп бүр дээр хэдэн секунд ажилласныг тоолно. Төлөв солигдсон үеүдийг (09:00–10:15
ажилласан, 10:15–10:30 гарсан …) болон сэжигтэй үеүдийг (зураг, таглагдсан камер) бүртгэнэ.

## Тогтмолууд
| Нэр | Утга | Утга учир |
|---|---|---|
| `TICK_SEC` | 1.0 | Хэдэн секунд тутам шалгах |
| `FLUSH_SEC` | 30.0 | Хэдэн секунд тутам дискэнд хадгалах (`storage.py`) |
| `MAX_GAP_SEC` | 10.0 | Хоёр шалгалтын хооронд үүнээс урт завсар = компьютер унтсан → тоолохгүй |
| `APP_SETTLE_SEC` | 1.0 | Апп солигдоод ийм удаан тогтвортой байвал самбар руу даруй мэдэгдэнэ (Alt+Tab шүүх) |
| `WORKING`, `AWAY` | `"working"`, `"away"` | Төлөвүүд |

## Шийдвэрийн дүрэм (`_tick`)
```
дэлгэц түгжээтэй эсвэл "Зогсоох" дарсан     → нотолгоогүй
камер ажиллаж байвал                         → царай харагдсан ЭСВЭЛ сүүлийн 5 сек гар/хулгана хөдөлсөн
камергүй бол                                 → сүүлийн 5 мин (no_camera_idle_timeout_sec) гар/хулгана хөдөлсөн

нотолгоотой          → энэ секунд ажилласан (идэвхтэй аппад нэмнэ), төлөв = "ажиллаж байна"
нотолгоогүй, 20 сек болоогүй (away_grace_sec) → шийдвэрийг хойшлуулна (_pending): эргэж ирвэл ажилд, үгүй бол гарсанд
нотолгоогүй, 20 сек өнгөрсөн → төлөв = "гарсан", тэр 20 сек ч гарсанд тооцогдоно
```
Мөн: шөнө дунд өдөр солигдох, компьютер унтаад сэрэх (завсрыг тоолохгүй) тохиолдлуудыг зохицуулна.

## `Tracker` класс
| Функц | Юу хийдэг |
|---|---|
| `start()` / `stop()` | Thread асаах/зогсоох. `stop` баталгаажаагүй хугацааг (`_pending`) ажилд тооцохгүйгээр хадгална. |
| `snapshot()` | Цонх болон хавтсанд илгээх одоогийн төлөв: `status`, `status_text`, `paused`, `app`, `work_seconds`, `away_seconds`, `camera_ok`, `face_visible`, `camera_state`, `top_apps`. |
| `set_paused(bool)` | **"Зогсоох / Үргэлжлүүлэх"**. Зогсооход төлөв "гарсан" болж, камерыг хаалгана (`presence.set_paused`), зогссон хугацаа ажилласан цагт нэмэгдэхгүй. |
| `flush_now()` | Хадгалаагүй өөрчлөлтийг даруй дискэнд (хавтас руу илгээхийн өмнө дуудагддаг). |
| `_tick()` | Дээрх дүрэм — секунд тутам. |
| `_app_settled(app, mono)` | Апп солигдоод 1 сек тогтвортой болсныг илрүүлнэ → `on_app_change()`. |
| `_switch(status, at)` | Төлөв солих: хуучин үеийг хааж шинийг нээнэ, `on_status_change()`. |
| `_set_flag(kind, now)` | Сэжигтэй үе (static / blocked) эхэлсэн/дууссаныг бүртгэнэ. |
| `_flush(now)` | Хуримтлагдсан апп-секунд, ажилласан/гарсан хугацаа, үеийн төгсгөлийг `storage`-д. |

## Callback-ууд (`app.py` холбодог)
- `on_status_change` → `cloud.poke` (төлөв, сэжигтэй үе солигдоход өдрийн дүнг даруй илгээх)
- `on_app_change` → `cloud.poke_live` (апп солигдоход зөвхөн одоогийн төлөв — самбарт ≤ 5 сек)
- `on_report_due(now)` → `ReportScheduler` (минут тутам)

## Анхаарах
- Админы тохиргоо (`away_grace_sec`, `input_counts_as_presence` …) `cfg`-ээр орж ирдэг бөгөөд tracker секунд тутам дахин уншдаг
  тул програмыг дахин эхлүүлэх шаардлагагүй.
- Зураг (хөдөлгөөнгүй царай) илэрсэн үед `presence` `last_face_time`-г шинэчлэхгүй → царай харагдахгүй гэж тооцогдоно.
