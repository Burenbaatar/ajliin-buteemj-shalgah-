# `worktracker/system.py` — лог, нэг хувь, автоматаар эхлэх

← [Буцах](../../README.md)

## Юу хийдэг
Үйлдлийн системтэй холбоотой жижиг ажлууд.

| Функц | Юу хийдэг |
|---|---|
| `setup_logging()` | `%APPDATA%\AjliinButeemj\app.log` — 1 MB хүрэхээр шинэ файл, 3 хуучныг хадгална. Алдаа хайхад эхлээд үүнийг үзнэ. |
| `ensure_single_instance(wait_sec)` | `127.0.0.1:48213` порт эзэлж програм **нэг л хувь** ажиллахыг баталгаажуулна (хоёр хувь цагийг давхар тоолохоос). Шинэчлэлийн дараа хуучин процесс хаагдахыг `wait_sec` хүлээнэ. |
| `start_instance_listener(on_show)` | Хоёр дахь хувь "show" илгээвэл ажиллаж буй цонхыг гаргаж ирнэ. |
| `signal_running_instance()` | Хоёр дахь хувь — ажиллаж буйд "show" илгээнэ. |
| `release_single_instance()` | Шинэчлэхийн өмнө портыг суллана. |
| `set_autostart(enabled)` | Компьютер асахад эхлэх: Windows — бүртгэлийн `HKCU\…\Run` → `"…\AjliinButeemj.exe" --background`; macOS — LaunchAgent. Зөвхөн exe/.app хувилбарт; exe-ийн одоогийн замыг бичдэг (exe-г зөөвөл дараагийн эхлэлд шинэчлэгдэнэ). |
| `enable_hidpi()` | Windows дээр өндөр нягтралтай дэлгэцэнд цонх бүдэг харагдахаас сэргийлнэ. |
