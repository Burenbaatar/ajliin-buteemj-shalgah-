# `worktracker/dashboard.py` — админы самбар

← [Буцах](../../README.md)

## Юу хийдэг
Админы компьютер дээр, админ нууц үгээр нээгддэг том цонх. Хавтаснаас бүх ажилтны өгөгдлийг уншиж (`dashdata.py`)
таб бүрт харуулна, мөн админы үйлдлүүдийг (хэлтэс, тохиргоо, хүн устгах) хийнэ.

| Таб | Агуулга |
|---|---|
| **Ажилтнууд** (өдөр) | Дээд талд KPI (ажиллаж байна / гарсан / офлайн / хоцорсон / ирээгүй / сэжигтэй). Хүн бүрийн мөр: нэр + хэлтэс, одоогийн төлөв ба хэзээнээс, одоогийн апп, ажилласан, гарсан, ирсэн–явсан, хоцорсон, бүтээмж %, **өдрийн явцын шугам**. Мөр дээр дарвал дэлгэрэнгүй цонх. |
| **7 хоног** | Хүн × өдөр хүснэгт, ажилласан цаг (ногооны өтгөн нь цагтай пропорциональ), ирээгүй ажлын өдөр улаанаар. |
| **Хэрэглэгчид** | Нэр, компьютер, хэлтэс, төлөв. Нэр засах, хэлтэс оноох, идэвхгүй болгох, **Бүрмөсөн устгах**, **Устгасан хүмүүс…** (сэргээх). |
| **Хэлтэс** | Нэмэх, нэр солих, устгах, хэлтсийн Telegram чат. |
| **Тохиргоо** | Ажлын хуваарь (эхлэх/дуусах, цай, хоцролтын хүлцэл, ажлын өдрүүд), илрүүлэлт (гарсан гэх сек, гар/хулгана, зураг илрүүлэх), бүтээмжтэй/бүтээмжгүй апп, Telegram (токен, чат олох, туршиж илгээх, босгууд). |

## Шинэчлэлт — хоёр түвшин
| Тогтмол | Утга | Юу |
|---|---|---|
| `REFRESH_MS` | 30 000 | Бүтэн уншилт (`dashdata.fetch_raw`): профайл, хэлтэс, өдрийн дүн, 7 хоног, тохиргоо |
| `LIVE_MS` | 2 000 | Зөвхөн `live.json`-ууд (`fetch_live`) → өөрчлөгдсөн бол Өдөр табыг дахин зурна. Ажилтан апп солиход ≤ 5 сек-д харагдана. Зөвхөн өнөөдрийг харж байхад, цонх жижигрээгүй үед. |

## Гол функцууд
| Функц | Юу хийдэг |
|---|---|
| `Dashboard(root, api, profile, bg)` | Цонх, табуудыг үүсгээд анхны уншилт. |
| `refresh()` / `_loaded(raw)` | Бүтэн уншилт арын thread-д → табуудыг зурна → дараагийн 30 сек. |
| `_live_tick()` / `_live_loaded(live)` | 2 сек тутмын live уншилт; өөрчлөлтгүй бол дахин зурахгүй. |
| `_render_day()` | Өдөр табын KPI + Canvas дээрх мөрүүд. |
| `draw_timeline(...)` | Өдрийн явц: ногоон = ажилласан, улаан = гарсан, саарал = цайны цаг, босоо зураас = ажлын эхлэл/төгсгөл, улбар шар = сэжигтэй үе. |
| `_render_week()` | 7 хоногийн хүснэгт. |
| `_save_user()`, `_remove_user()`, `_show_removed()` | Хэрэглэгчид табын үйлдлүүд (`share.rpc("wt_admin_…")`). |
| `_save_dept()`, `_save_dept_chat()`, `_delete_dept()` | Хэлтэс. |
| `_fill_settings()`, `_collect_settings()`, `_save_settings()` | Тохиргоо уншиж, шалгаж (ЦЦ:ММ, тоо), хадгалах. |
| `_find_chats()`, `_test_telegram()` | Telegram ботын чатуудыг олох, туршилтын мессеж. |
| `export_csv()` | Өдрийн хүснэгтийг CSV (Excel-д кирилл зөв). |
| `DetailWindow` | Нэг хүний өдөр: картууд (ажилласан, гарсан, ирсэн–явсан, бүтээмж, хоцорсон, эрт явсан, илүү цаг, програм хаалттай), явцын шугам, сэжигтэй үеүд, апп бүр ангиллаар. |

## Анхаарах
- Бүх унших/бичих ажил арын thread-д (`bg.run`) — цонх хөлдөхгүй.
- Шинэ тохиргоо нэмэх бол: `_build_settings_tab`-д талбар, `_collect_settings`-д утга, ажилтанд хүргэх бол `config.COMPANY_KEYS`-д түлхүүр.
