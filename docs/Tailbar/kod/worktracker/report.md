# `worktracker/report.py` — өдрийн тайлан

← [Буцах](../../README.md)

## Юу хийдэг
Ажилтны **нэг өдрийн** тайланг гурван хэлбэрээр үүсгэнэ: HTML (хөтөчид нээх), текст (имэйл, Telegram), CSV (Excel).
Цонхны **"Тайлан"** товч, `--report`, имэйл/Telegram илгээлт ашигладаг. Өгөгдлийг ажилтны өөрийн компьютерээс (`storage.py`) авна.

## Тайланд юу байдаг
- Ажилласан, ажлаас гарсан хугацаа; анх ирсэн / сүүлд харагдсан цаг
- Апп тус бүр дээр ажилласан хугацаа ба хувь (баганан диаграмтай)
- Ажлаас гарсан үеүд (`min_away_period_min`-ээс урт — анхдагч 1 мин)
- "Дэлгэцийн зураг, камерын бичлэг хадгалаагүй" гэсэн тэмдэглэл

## Функцууд
| Функц | Юу хийдэг |
|---|---|
| `build_report(storage, day, employee, min_away_min)` | `{"day", "employee", "data", "text", "html", "csv"}` буцаана. |
| `save_report(report)` | `%APPDATA%\AjliinButeemj\reports\<өдөр>_<нэр>.html` ба `.csv` (CSV нь Excel-д кирилл зөв харагдах UTF-8 BOM-той). |
| `merge_periods(periods)` | Дараалсан ижил төлөвтэй үеүдийг нэгтгэнэ (програм дахин эхэлсэн г.м.). `cloud.py` хавтас руу илгээхдээ ч ашигладаг. |
| `fmt_dur(seconds)` | `3725` → `"1 ц 02 мин"`. |
