# `worktracker/updater.py` — автомат шинэчлэл

← [Буцах](../../README.md)

## Юу хийдэг
Ажилтны програм **30 минут тутам** (мөн эхлэх бүрт) админы хавтасны `update\version.json`-г уншиж, өөрөөсөө шинэ хувилбар
байвал `update\AjliinButeemj.exe`-г татаж, **SHA-256**-аар шалгаад өөрийгөө сольж дахин эхэлнэ. Админ зөвхөн
`python build.py --publish` хийнэ — ажилтнуудад дахин тараах шаардлагагүй.

## `version.json`
```json
{ "version": "3.1.1", "file": "AjliinButeemj.exe", "size": 75321492,
  "sha256": "018f6d…", "published_at": "2026-11-13T11:19:13" }
```

## Функцууд
| Функц | Юу хийдэг |
|---|---|
| `check_share(share, current)` | Хавтас холбогдсон, `version.json` уншигдсан, хувилбар нь одоогийнхоос **том**, файл байгаа бол `{version, path, size, sha256}`; үгүй бол `None`. |
| `download(info, progress, dest_dir)` | Хавтаснаас `%APPDATA%\AjliinButeemj\update\`-д хуулж, хэмжээ + SHA-256 тулгана. Таарахгүй бол (гэмтсэн эсвэл хэн нэгэн сольсон) **татгалзана**. |
| `apply(path)` | Windows: ажиллаж буй exe-г `.old.exe` болгож нэрлээд (Windows зөвшөөрдөг) шинийг байрлуулж `--updated`-тэй дахин эхлүүлнэ. macOS: `.app`-г задалж сольно. Алдаа гарвал хуучныг буцаана. |
| `cleanup()` | Дараагийн эхлэлд `.old.exe` болон татсан түр файлыг устгана. |
| `supported()` | Зөвхөн exe/.app хувилбарт (Python-оор ажиллуулахад шинэчлэхгүй). |
| `version_tuple(v)` | `"3.1.1"` → `(3, 1, 1)` харьцуулалт. |

## Хэн дууддаг
`gui.MainWindow.check_update()` — эхлэх үед болон цонх нуугдсан үед **асуулгүй** суулгана; цонх нээлттэй бол "⬇ Шинэ хувилбар — Шинэчлэх"
товч гаргана. Унтраах: `config.json` → `"auto_update": false`.

## Аюулгүй байдал
`update\` хавтсыг ажилтнууд **зөвхөн уншина** (`build.py` `icacls`-аар тохируулна), мөн SHA-256 шалгадаг тул хэн нэгэн хортой
exe тавьж бүх компьютерт тараах боломжгүй.
