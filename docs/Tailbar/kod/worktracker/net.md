# `worktracker/net.py` — HTTPS туслах

← [Буцах](../../README.md)

## Юу хийдэг
Интернэт рүү (Telegram, имэйл) аюулгүй холбогдоход хэрэгтэй хоёр функц. Админы хавтастай ажиллахад **хэрэглэгддэггүй**
(тэр нь дотоод сүлжээний файл хуваалцалт).

| Функц | Юу хийдэг |
|---|---|
| `ssl_context()` | `certifi`-ийн гэрчилгээний багцтай SSL. PyInstaller-ээр багцалсан (ялангуяа macOS) програм системийн гэрчилгээг олж чаддаггүй тул хэрэгтэй. Нэг удаа үүсгээд дахин ашиглана. |
| `post_json(url, payload, headers, timeout)` | HTTPS POST; HTTP алдааны үед серверийн мессежтэй `RuntimeError`. |

## Хэн дууддаг
`notify.py` (Telegram, SMTP).
