# `worktracker/alerts.py` — Telegram мэдэгдэл

← [Буцах](../../README.md)

## Юу хийдэг
**Зөвхөн админы компьютер дээр** (тэнд хавтас байдаг, байнга асаалттай) 5 минут тутам хавтсыг шалгаж, асуудалтай ажилтны тухай
Telegram групп руу бичнэ. Нэг үйл явдлыг **нэг л удаа** мэдэгдэнэ.

| Мэдэгдэл | Нөхцөл | Босго (самбарын Тохиргооноос) |
|---|---|---|
| ⏰ Ирээгүй | Ажил эхэлснээс N мин өнгөрсөн ч өнөөдөр ажилласан цаг 0 | `alert_late_min` = 30 |
| 🚶 Удаан гарсан | "Гарсан" төлөв N минутаас удаан (цайны цагаас бусад үед) | `alert_away_min` = 40 |
| ⚠️ Програм хаалттай | Ажлын цагаар N мин мэдээлэл ирээгүй | `alert_offline_min` = 15 |
| 📷 / 🖼 Камер | Камер таглагдсан эсвэл хөдөлгөөнгүй царай (зураг?) | шууд |

Зөвхөн ажлын өдөр, ажлын цагт (`work_start`–`work_end`) шалгана. Мессеж хэлтсийн чат руу, мөн админы чат руу явна.

## Функцууд
| Нэр | Юу хийдэг |
|---|---|
| `collect(profiles, departments, live, today_rows, settings, sent, now)` | Дээрх дүрмүүдээр илгээх мессежүүдийн жагсаалт `[(чат, текст)]`. `sent`-д илгээснийг тэмдэглэж давтахгүй; 60 хоногоос хуучныг цэвэрлэнэ. Цонх, сүлжээгүй — цэвэр тооцоо. |
| `AlertRunner(share)` | Арын thread; `start()`, `stop()`. |
| `AlertRunner.run_once()` | Токен (`admin.json`) ба `alerts_enabled` байвал хавтаснаас уншиж `collect` → `notify.tg_send`. Илгээсэн түүх: `%APPDATA%\AjliinButeemj\alerts_log.json`. |
| `_zone(name)` | Цагийн бүс (`Asia/Ulaanbaatar`); Windows-д мэдээлэл байхгүй бол компьютерийн цаг. |

## Тохируулах
Самбар → Тохиргоо → Telegram: @BotFather-аас токен → ботыг группт нэмэх → "Чат олох" → админы чат; хэлтэс бүрийн чатыг Хэлтэс табаас.
Токен **хавтсанд биш**, зөвхөн админы компьютерийн `admin.json`-д хадгалагдана.
