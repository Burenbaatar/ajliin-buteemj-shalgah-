# `worktracker/storage.py` — ажилтны компьютер дээрх хадгалалт

← [Буцах](../../README.md)

## Юу хийдэг
Ажилтны цагийн бүртгэлийг **өөрийн компьютерт** энгийн JSON файлуудад хадгална (SQL, өгөгдлийн сан ашиглахгүй).
Админы хавтас холбогдохгүй байсан ч өгөгдөл алдагдахгүй — `cloud.py` эндээс уншиж хавтас руу хуулдаг.

## Хавтасны бүтэц
```
%APPDATA%\AjliinButeemj\users\<uid>\worktime\
  meta.json              — компьютерийн ID, "тайлан илгээсэн" тэмдэг г.м.
  days\2026-11-13.json   — нэг өдөр
```
Нэг өдрийн файл:
```json
{ "work_seconds": 15230.0, "away_seconds": 1800.0, "first_seen": "08:57:12", "last_seen": "17:45:03",
  "apps":    { "Microsoft Excel": 6200.0, "Google Chrome": 4100.0 },
  "periods": [ {"status": "working", "start": "08:57:12", "end": "10:15:40"}, … ],
  "flags":   [ {"kind": "blocked", "start": "11:02:00", "end": "11:05:30"} ] }
```

## `Storage` класс
| Функц | Юу хийдэг |
|---|---|
| `add_totals(day, apps, work, away, first, last)` | Tracker 30 сек тутам хуримтлуулсан секундуудыг нэмнэ; анх ирсэн/сүүлд харагдсан цагийг шинэчилнэ. |
| `open_period(day, status, start)` → id | Шинэ үе (ажиллаж байна / гарсан) эхлүүлнэ. id нь `"<өдөр>#<дугаар>"`. |
| `update_period_end(id, end)` | Үргэлжилж буй үеийн төгсгөлийг сунгана. |
| `open_flag` / `update_flag_end` | Сэжигтэй үе (зураг / таглагдсан камер) — ижил зарчмаар. |
| `get_day(day)` | Тайлан, хавтас руу илгээхэд: апп-уудыг хугацаагаар эрэмбэлсэн, үеүдийг цагаар эрэмбэлсэн dict. |
| `days_with_data()` | Ажилласан цагтай бүх өдрийн жагсаалт (нөхөж илгээх, тайлан нөхөхөд). |
| `set_meta` / `get_meta` | `meta.json`-д жижиг утга (компьютерийн ID, `sent:email:<өдөр>`). |

## Найдвартай байдал
- Бичилт бүр: түр файл → `os.replace` (гэнэт унтарсан ч хагас файл үлдэхгүй).
- Эвдэрсэн JSON олдвол `.broken` болгож нэрлээд шинээр эхэлнэ (програм унахгүй).
- Сүүлийн 40 өдрийг санах ойд кэшлэнэ; thread-аас хамгаалсан түгжээтэй.
