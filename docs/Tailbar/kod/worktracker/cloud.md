# `worktracker/cloud.py` — админы хавтас руу хуулах хуваарь

← [Буцах](../../README.md)

## Юу хийдэг
Арын thread дээр ажиллаж, ажилтны өгөгдлийг **хэзээ** админы хавтас руу хуулахыг шийднэ (хуулах ажлыг өөрөө `share.py` хийнэ).
Нэр нь "cloud" ч одоо үүл биш — админы хуваалцсан хавтас.

| Хэзээ | Юуг | Функц |
|---|---|---|
| Минут тутам (`push_interval_sec` = 60) | Өнөөдрийн бүтэн дүн + одоогийн төлөв | `push_day` |
| Төлөв солигдоход (ажиллаж ↔ гарсан, камер, зогсоох) | Мөн адил, даруй (~1 сек тогтворжуулаад) | `poke()` → `push_day` |
| Апп солигдоход | **Зөвхөн** одоогийн төлөв (`live.json`), хамгийн багадаа 2 сек зайтай | `poke_live()` → `push_live` |
| Эхлэхэд, хавтас дахин холбогдоход | Сүүлийн 7 хоногийн өдрүүд (нөхөх) | `_push_history` |
| 10 мин тутам | Админы тохиргоог уншиж `cfg`-д хэрэглэх | `pull_settings` |
| Програм хаагдахад | Эцсийн дүн + "Офлайн" | `stop()` |

## Тогтмолууд
| Нэр | Утга | |
|---|---|---|
| `HISTORY_DAYS` | 7 | Хэдэн өдрийг нөхөж бичих |
| `MAX_APPS` | 60 | Нэг өдөрт хамгийн ихдээ хэдэн апп илгээх |
| `SETTINGS_EVERY_SEC` | 600 | Тохиргоо татах давтамж |
| `LIVE_MIN_GAP_SEC` | 2.0 | Апп хурдан солигдоход live бичилтийн хамгийн бага зай |

## `CloudSync` класс
| Функц | Юу хийдэг |
|---|---|
| `start()` / `stop()` | Thread асаах / зогсоох (зогсооход эцсийн "Офлайн" бичилт). |
| `poke()` / `poke_live()` | Tracker-ийн дохио — дээрх хүснэгтийг үз. |
| `_run()` | Үндсэн давталт: бүтэн бичилт хийх цаг болсон уу, live хүсэлт байна уу гэж шийдэж хүлээнэ. |
| `push_day(day, live, status)` | `storage.get_day` → апп, үе, сэжигтэй үеийг бэлдээд `share.rpc("wt_push", …)`. |
| `push_live()` | `p_live_only=True` — өдрийн файлыг бичихгүй, зөвхөн `live.json`. |
| `pull_settings()` | `company.json` → `COMPANY_KEYS` (гарсан гэх хугацаа, зураг илрүүлэх …)-ийг `cfg`-д. |
| `status_text()` | Цонхонд: "Холбогдсон (5 сек өмнө)" / "Алдаа: Админы компьютер олдсонгүй…". |
| `_ok()` / `_fail(exc)` | Амжилт/алдааг тэмдэглэнэ; алдааны дараа өмнөх өдрүүдийг дахин нөхөж бичихээр тэмдэглэнэ. Ижил алдааг дахин дахин логлохгүй. |

## Анхаарах
- Илгээлт бүр **нийт дүнгээр солидог** (нэмдэггүй) тул давтан илгээх нь аюулгүй.
- Хавтас холбогдохгүй үед алдааг чимээгүй тэмдэглээд дараагийн минутад дахин оролдоно.
