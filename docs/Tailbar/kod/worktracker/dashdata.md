# `worktracker/dashdata.py` — самбарын тооцоо

← [Буцах](../../README.md)

## Юу хийдэг
Самбарын "тархи": хавтаснаас түүхий өгөгдлийг уншиж, хүн тус бүрээр нэгтгэж, ажлын хуваарьтай харьцуулж **хоцролт, эрт явалт,
илүү цаг, програм хаалттай үе, ирээгүй, бүтээмж %**-ийг тооцно. Цонх зурах кодгүй — зөвхөн тооцоо (тиймээс туршихад хялбар).

## Тогтмолууд
| Нэр | Утга | |
|---|---|---|
| `OFFLINE_AFTER_SEC` | 180 | Сүүлийн мэдээллээс 3 мин өнгөрвөл "Офлайн" |
| `STATUS_TEXT`, `FLAG_TEXT`, `CAMERA_TEXT` | | Самбар дээрх Монгол бичвэрүүд |
| `DEFAULT_SETTINGS` | 09:00–18:00, цай 13:00–14:00, Да–Ба, хүлцэл 5 мин | Админ тохируулаагүй үеийн хуваарь |

## Унших
| Функц | Юу хийдэг |
|---|---|
| `fetch_raw(api, day)` | Нэг өдрийн бүх түүхий өгөгдөл: профайл, хэлтэс, live, тэр өдрийн дүн, сүүлийн 7 хоног, тохиргоо. |
| `fetch_live(api)` | Зөвхөн одоогийн төлөвүүд (2 сек тутмын шинэчлэлтэд). |
| `build_raw(raw, live=None)` | `fetch_raw`-ийн үр дүнг `build`-ээр нэгтгэнэ; `live` өгвөл шинээр нь солино. |
| `build(...)` | Хүн бүрийн бүрэн мөр: нэр, хэлтэс, төлөв, өдрийн дүн, 7 хоног, ирээгүй өдрүүд, хуваарийн үзүүлэлт, бүтээмж, сэжигтэй үе. Ажиллаж байгаа → гарсан → офлайн дарааллаар эрэмбэлнэ. |

## Тооцоо
| Функц | Юу хийдэг |
|---|---|
| `live_status(live)` | `working` / `away` / `offline` (3 мин мэдээлэлгүй бол офлайн). |
| `merge_daily(rows)` | Нэг хүн хэд хэдэн компьютер дээр ажилласан бол нэгтгэнэ. |
| `schedule_metrics(d, has_day, s, day)` | **Хоцорсон** (ирсэн − эхлэх > хүлцэл), **эрт явсан**, **илүү цаг** (ажлын цагаас гадуур; амралтын өдөр бүгд), **програм хаалттай** (ирсэн–явсан хооронд, ажлын цагт, цайны цагаас бусад ≥ 1 мин завсар), **цайны цагийн гарсан** (хасагдана), **ирээгүй**. |
| `productivity(apps, s)` / `categorize(app, s)` | Аппыг админы түлхүүр үгээр бүтээмжтэй / бүтээмжгүй / бусад гэж ангилж хувийг тооцно. |
| `flag_totals(flags)` | Зураг / таглагдсан камерын нийт секунд. |
| `day_range(...)` | Явцын шугамын хүрээ (хамгийн багадаа 08:00–18:00). |
| `parse_ts`, `to_sec`, `hm_sec`, `overlap`, `ago_text`, `settings_with_defaults` | Цаг хөрвүүлэх жижиг туслахууд ("5 мин", "2ц 15м"). |

## Хэн дууддаг
`dashboard.py` (самбар). Telegram мэдэгдэлд өөрийн тооцоо (`alerts.py`) байдаг.
