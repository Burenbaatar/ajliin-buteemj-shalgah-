# `worktracker/__init__.py` — нэр ба хувилбар

← [Буцах](../../README.md)

## Юу хийдэг
`worktracker` хавтсыг Python багц болгодог бөгөөд програм даяар ашиглагддаг гурван утгыг агуулна.

| Нэр | Утга | Хаана хэрэглэгддэг |
|---|---|---|
| `APP_NAME` | `"AjliinButeemj"` | Хавтасны нэр (`%APPDATA%\AjliinButeemj`), tray, автомат эхлэлийн бүртгэл |
| `APP_TITLE` | `"Ажлын бүтээмж"` | Цонхны гарчиг, мессеж |
| `__version__` | `"3.1.1"` | Шинэчлэл шалгах (`updater.check_share`), `--selftest`, `build.py --publish` |

## Анхаарах
Ажилтнуудыг шинэчлэх бүрт **`__version__`-ийг нэмэгдүүлнэ** (жишээ `3.1.1` → `3.1.2`) — шинэ хувилбар хуучнаасаа том байж л
програмууд татаж суулгана. `AjliinButeemj.spec`-ийн `VERSION`-ийг ижил болгоно.
