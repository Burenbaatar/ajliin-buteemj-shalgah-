# Програм бүхэлдээ хэрхэн ажилладаг вэ

← [Буцах](../README.md)

## Нэг өгүүлбэрээр
Ажилтан бүрийн компьютер дээр **`AjliinButeemj.exe`** tray-д нуугдаж ажиллаад, камер болон гар/хулганаар хүн байгаа эсэхийг
**секунд тутам** шалгаж, апп бүр дээр хэдэн секунд ажилласныг тоолно. Үр дүнгээ **JSON** файл болгож **админы компьютерийн
хуваалцсан хавтас** руу хуулна. Админ тэр хавтаснаас **самбараар** бүх ажилтныг харна. Сервер, өгөгдлийн сан, IP хэрэггүй.

## Схем
```
╔══════════════ Ажилтны компьютер ══════════════╗          ╔══════════ Админы компьютер (DESKTOP-…) ══════════╗
║                                               ║          ║                                                  ║
║  presence.py ─ камер: царай байна уу? (1 сек) ║          ║  C:\AjliinButeemjData\  (\\…\AjliinButeemj)      ║
║  activity.py ─ апп, гар/хулгана, түгжээ       ║          ║    company.json   ← тохиргоо, хэлтэс (админ)     ║
║        │                                      ║          ║    people\<uid>\  ← ажилтан бүрийн өгөгдөл       ║
║        ▼                                      ║  JSON    ║       profile.json, live.json, days\<өдөр>.json  ║
║  tracker.py ─ "ажиллаж байна / гарсан"        ║ ───────► ║    update\        ← шинэ exe (build --publish)   ║
║        │ 30 сек                               ║          ║                                                  ║
║        ▼                                      ║ ◄─────── ║  dashboard.py + dashdata.py → самбар (2/30 сек)  ║
║  storage.py ─ өөрийн компьютерт JSON          ║ тохиргоо ║  alerts.py → Telegram (5 мин)                    ║
║        │ 60 сек / төлөв, апп солигдоход       ║ шинэчлэл ║                                                  ║
║        ▼                                      ║          ╚══════════════════════════════════════════════════╝
║  cloud.py → share.py ─ хавтас руу бичих       ║
║  gui.py ─ цонх + tray (Зогсоох, Тайлан, Гарах)║
╚═══════════════════════════════════════════════╝
```

## Ажилтны компьютер дээр — нэг секундын амьдрал
1. **`presence.py`** арын thread дээр камераас кадр уншиж, царай олдвол `last_face_time`-г шинэчилнэ. Зураг тавьсан
   (царай 2 мин огт хөдлөхгүй) эсвэл камер таглагдсан (30 сек хар) бол тэмдэглэнэ. **Кадр хадгалахгүй.**
2. **`tracker.py`** секунд тутам (`TICK_SEC = 1`):
   - `activity.py`-ээс идэвхтэй апп, гар/хулгана хэдэн секунд хөдлөөгүй, дэлгэц түгжигдсэн эсэхийг авна;
   - "нотолгоо" байна уу (царай / сүүлийн 5 сек гар хөдөлсөн) гэж шийднэ;
   - байвал тэр секундийг тухайн аппад **ажилласан**, үгүй бол 20 сек хүлээж (`away_grace_sec`) **гарсан**-д тооцно;
   - 30 сек тутам `storage.py`-д хадгална.
3. **`cloud.py`** минут тутам өнөөдрийн дүнг, төлөв солигдоход даруй, апп солигдоход зөвхөн одоогийн төлөвийг (`live.json`)
   **`share.py`**-ээр админы хавтас руу бичнэ.
4. **`gui.py`** секунд тутам цонхыг шинэчилнэ (таймер, апп, камер), tray дүрсийг ногоон/улаан/шар болгоно.

## Админы компьютер дээр
- Админ ч өөрөө exe ажиллуулдаг (өөрийн цаг бүртгэгдэнэ) — гэхдээ **`admin.json`** байгаа тул "Самбар" товч гарна.
- **`dashboard.py`** хавтаснаас: 30 сек тутам бүх өгөгдлийг, 2 сек тутам зөвхөн `live.json`-уудыг уншиж, **`dashdata.py`**-ээр
  хоцролт, илүү цаг, бүтээмж %-ийг тооцоод харуулна.
- **`alerts.py`** 5 мин тутам ирээгүй / удаан гарсан / програм хаалттай / камер таглагдсан хүнийг Telegram-аар мэдэгдэнэ.

## Цаг хугацааны тойм
| Юу | Хэр олон | Хаана |
|---|---|---|
| Камер, апп, гар/хулгана шалгах | 1 сек | `tracker.TICK_SEC`, `camera_check_interval_sec` |
| Царай харагдахгүй → "гарсан" | 20 сек | `away_grace_sec` (админ өөрчилнө) |
| Камергүй үед гар хөдлөхгүй → "гарсан" | 5 мин | `no_camera_idle_timeout_sec` |
| Өөрийн компьютерт хадгалах | 30 сек | `tracker.FLUSH_SEC` |
| Хавтас руу бүтэн дүн | 60 сек | `cloud.push_interval_sec` |
| Апп солигдоход самбарт | ≤ 5 сек | `tracker.APP_SETTLE_SEC`, `cloud.LIVE_MIN_GAP_SEC`, `dashboard.LIVE_MS` |
| Самбарын бүтэн шинэчлэлт | 30 сек | `dashboard.REFRESH_MS` |
| "Офлайн" гэж үзэх | 3 мин | `dashdata.OFFLINE_AFTER_SEC` |
| Админы тохиргоо ажилтанд хүрэх | 10 мин | `cloud.SETTINGS_EVERY_SEC` |
| Telegram шалгалт | 5 мин | `alerts.EVERY_SEC` |
| Шинэ хувилбар шалгах | 30 мин | `updater.CHECK_EVERY_SEC` |

## Ажилтныг хэрхэн таньдаг вэ
Нэвтрэлт байхгүй. `share.make_uid()` → **`<Windows хэрэглэгч>@<компьютерийн нэр>`** (жишээ: `bat@PC-01`).
Энэ нь админы хавтсанд `people\<uid>\` хавтасны нэр болно. Нэрийг (жишээ: "Бат") анх нээхэд нэг удаа асууна.

## Хавтсанд хэрхэн нэвтэрдэг вэ
`--admin-setup` админы компьютер дээр тусгай Windows хэрэглэгч `ajliinbuteemj` үүсгэж, хавтсыг түүнд хуваалцана.
Хаяг + энэ хэрэглэгчийн нууц үг **`share.json`**-д бичигдэж, exe дотор багцлагдана. Ажилтны програм хавтас харагдахгүй бол
`net use`-ээр автоматаар нэвтэрнэ (`share.ensure_connected`).

## Өгөгдөл алдагдахгүй байх
- Хавтас холбогдохгүй үед ч бүх зүйл ажилтны компьютерт (`storage.py`) хадгалагдана; холбогдмогц сүүлийн 7 хоногийг нөхөж бичнэ.
- Файл бүрийг түр файлд бичээд `os.replace`-ээр солино — гэнэт унтарсан ч хагас файл үлдэхгүй.
- Өөр компьютер яг уншиж байхад солих гэвэл Windows түр хориглодог тул бичих/унших хоёулаа хэд дахин оролддог.

## Хамгаалалт ба хязгаар
- Ажилтан бүр зөвхөн **өөрийн** хавтсанд бичнэ; `update\`-г **зөвхөн уншина** (хортой exe тавьж чадахгүй).
- Гэхдээ бүгд нэг тусгай хэрэглэгчээр нэвтэрдэг тул техникийн мэдлэгтэй хүн бусдын JSON-г уншиж/засаж чадна.
- Самбар зөвхөн админы компьютер дээр, админ нууц үгээр (`admin.json`, PBKDF2 хэш) нээгдэнэ.
