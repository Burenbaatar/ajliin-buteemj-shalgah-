# Ажлын бүтээмж

Windows-ийн нэг програм (`.exe`). Компьютер асахад **арын горимд** (зөвхөн tray дүрс) эхэлж,
**камераар** ажилтан компьютерийн өмнө байгаа эсэхийг шалгаж, байхад цаг тоолж, гарахад зогсооно. Апп тус бүр
дээр хэдэн минут ажилласныг бүртгэнэ. Өгөгдлөө **админы компьютер** руу илгээнэ — админ самбараас бүх ажилтныг харна.

- **IP, нэвтрэлт, гадны сервер хэрэггүй.** Ажилтныг Windows хэрэглэгч + компьютерийн нэрээр автоматаар таньна
  (анх нээхэд нэрээ л нэг удаа бичнэ). Админы компьютерийг **нэрээр нь** олно.
- **Хүн бүр зөвхөн өөрийнхөө өгөгдлийг** илгээнэ: анх холбогдохдоо хувийн түлхүүр авч, дараа нь хүсэлт бүрт гарын
  үсэг зурна. exe дотор нууц үг байхгүй — задалсан ч бусдын цагийг харж, засаж чадахгүй.
- **Зөвхөн Python**, SQL ашиглахгүй. Бүх өгөгдөл энгийн JSON файл.
- Дэлгэц бичихгүй, дэлгэцийн зураг авахгүй, камерын зураг хадгалахгүй (кадр санах ойд шалгагдаад устана).
- Цонхны гарчиг биш, зөвхөн **аппын нэр**ийг бүртгэнэ ("Microsoft Excel"). Браузерын хувьд дэлгэц дээр нээлттэй
  байгаа табын **сайтын нэр**ийг ("Chrome · YouTube", "Edge · Gmail") — видео, имэйлийн гарчиг хадгалагдахгүй (сайт нэрээ
  гарчигтаа бичдэггүй бол табын гарчиг өөрөө, 40 тэмдэгт хүртэл).

## Хэрхэн ажилладаг вэ

```
 Ажилтны компьютер (tray)                         Админы компьютер (програм нь сервертэй, TCP 47815)
 ─────────────────────────                        ─────────────────────────────────────────────
 камер + апп → цаг тоолно                         C:\AjliinButeemjData\   (хуваалцахгүй)
 → өөрийн компьютерт JSON                           company.json   (тохиргоо, хэлтэс — админ)
 → минут тутам + апп/төлөв ─ HTTP, гарын үсэг ──►   people\<хэрэглэгч@компьютер>\ …
   солигдоход                                       devices.json   (ажилтан бүрийн түлхүүр)
 ◄──── тохиргоо, шинэ хувилбар ─────────────────── Самбар (админ нууц үгээр) · Telegram мэдэгдэл
```

| Хэсэг | Технологи |
|---|---|
| Хүн илрүүлэх | OpenCV YuNet + MiniFASNetV2 зураг/дэлгэцийн anti-spoof загвар, секунд тутам |
| Царай таних (заавал биш) | OpenCV + SFace — бүртгэлтэй ажилтан мөн эсэхийг 15 сек тутам |
| Идэвхтэй апп | pywin32 + psutil |
| Гар/хулгана | `GetLastInputInfo` |
| Компьютер дээр | JSON файлууд (өдөр бүр нэг файл) |
| Админ руу | Админы компьютер дээрх жижиг сервер (Python `http.server`), HMAC гарын үсэг — JSON |
| Цонх, tray, самбар | Tkinter + pystray |
| Суулгах | PyInstaller → `AjliinButeemj.exe` |

- Сервер ажилтанд **зөвхөн өөрийн** `people\<хэрэглэгч@компьютер>\` хэсэгт бичихийг зөвшөөрнө; бусдынхыг уншуулахгүй.
- Админы компьютер унтарсан / сүлжээ тасарсан үед өгөгдөл ажилтны компьютерт хадгалагдсаар байж,
  холбогдмогц сүүлийн 7 хоногийг **нөхөж** хуулна.

Төлөв тодорхойлох дүрэм:

1. Камерт царай харагдаж байвал → **Ажиллаж байна** (тухайн үеийн идэвхтэй аппад цаг нэмнэ).
2. Царай харагдахгүй болбол 20 сек хүлээнэ (админ өөрчилж болно). Энэ хугацаанд эргэж харвал алдагдалгүй.
3. Түүнээс удвал → **Ажлаас гарсан**. Тэр 20 секунд ч "гарсан" хугацаанд орно.
4. Гар/хулгана хөдөлж байвал (доош харж бичиж байгаа гэх мэт) хүн байна гэж үзнэ.
5. Дэлгэц түгжигдвэл (Win+L) шууд **Ажлаас гарсан**.
6. Камер олдохгүй бол гар/хулганы хөдөлгөөнөөр л шалгана (5 мин хөдлөхгүй бол гарсан).
7. Компьютер унтсан хугацааг тоолохгүй. Програм хаагдвал самбарт **Офлайн** болно.

## Нэг удаагийн тохиргоо (админ, ~5 минут)

1. **Админы компьютер:** оффисын, ажлын цагаар **асаалттай** байдаг компьютер (ажилтнуудтай нэг сүлжээнд).
   Python 3.9+ суулгана (<https://www.python.org/downloads/>, "Add python.exe to PATH" чагтлах).
2. **Админ тохиргоо** — төслийн хавтаст:
   ```
   python main.py --admin-setup
   ```
   Windows админ эрх (UAC) асууна. Автоматаар:
   - админ нууц үг тавина (самбар нээхэд асууна);
   - өгөгдлийн хавтас `C:\AjliinButeemjData` (бусдад хуваалцахгүй);
   - Windows firewall-д серверийн порт **TCP 47815**-ыг (зөвхөн Private сүлжээнд) нээнэ;
   - `hub.json` бичнэ (энэ компьютерийн нэр + порт — нууц зүйлгүй).
3. **Бүтээх:** `python build.py --publish` → `dist\AjliinButeemj.exe`. `hub.json` exe дотор **багцлагдана** — ажилтан
   юу ч тохируулахгүй.
4. **Ажилтнуудад тараах:** `AjliinButeemj.exe`-г өгнө. Анх нээхэд нэрээ бичнэ — тэгээд л болоо.
5. **Хэлтэс, хуваарь:** Самбар → Хэлтэс → "Борлуулалт", "Нягтлан"…; Хэрэглэгчид (шинэ хүн шараар) → хэлтэс оноох;
   Тохиргоо → ажлын цаг, цайны цаг, ажлын өдрүүд, бүтээмжтэй/бүтээмжгүй апп, Telegram.

Админы компьютерийн сүлжээ **Private** (Settings → Network → Properties → Private network) байх ёстой.
`C:\AjliinButeemjData`-г тогтмол нөөцлөөрэй (20 хүн жилд ~10–20 MB).

## Ажилтны компьютерт

1. `AjliinButeemj.exe`-г нээнэ. Гарын үсэггүй .exe тул SmartScreen "More info → Run anyway" гэж асууж болно.
   Settings → Privacy & security → Camera → "Let desktop apps access your camera" асаалттай байх.
2. Анх нээхэд нэрээ бичнэ. Дараа нь компьютер асах бүрт **цонхгүйгээр** (зөвхөн tray дүрс) эхэлж цаг бүртгэнэ.
3. Шалгах: `AjliinButeemj.exe --selftest` (лог файлд) — "Админ руу: http://…:47815 — холбогдсон" гэж гарна.

Компьютер дээрх өгөгдөл, лог: `%APPDATA%\AjliinButeemj\`

## Tray (арын горим)

- Компьютер асахад програм `--background` горимд эхэлнэ: цонх гарахгүй, зөвхөн tray дүрс (ногоон = ажиллаж байна,
  улаан = гарсан).
- Tray дүрс → давхар дарж цонхыг нээнэ · баруун товч → "⏸ Зогсоох" · "Самбар (админ)" (админы компьютер дээр) ·
  "Програмыг хаах".
- **⏸ Зогсоох / ▶ Үргэлжлүүлэх** (цонх болон tray): цаг тоолохыг гараар зогсооно. Дарахад
  **шалтгаан асууна** (заавал; цуцалбал зогсохгүй) — шалтгаан админд даруй очиж, админы компьютерт tray
  мэдэгдэл (Telegram тохируулсан бол Telegram-аар ч) ирнэ, "Самбар" товч дээр "· N хүлээгдэж байна" гарна.
  Админы шийдвэрээр:

  | Шийдвэр | Ажилтны цонх | Самбар | Цаг |
  |---|---|---|---|
  | Хүлээгдэж байна | шар "⏸ Зогсоосон" | "Түр зогссон" | "гарсан"-д |
  | **Зөвшөөрсөн** | цэнхэр "⏸ Зогсоосон · зөвшөөрсөн" | "Түр зогссон ✓" | **ажилласан цагт нөхөгдөж орно** (таймер секунд тутам өснө) |
  | **Татгалзсан** | улаан "● Ажлаас гарсан" | "Гарсан · ✗ зогсолт татгалзсан" | "гарсан" хэвээр |

  Админ шийдмэгц ажилтанд tray мэдэгдэл ирнэ. "Тайлан" болон и-мэйл / Telegram-аар илгээх өдрийн тайланд
  зөвшөөрсөн зогсолт ажилласан цагт орж, "Түр зогсолт" хэсэгт шийдвэрийн хамт жагсаагдана. Зогсоосон үед
  **камер бүрэн унтарна** (гэрэл нь ч), үргэлжлүүлэхэд шууд асна.
- Цонхыг ✕ хаахад дахин tray руу нуугдана. Програмыг **бүрэн хаах**: цонхны доод талын улаан **Програмаас гарах** товч (эсвэл tray → "Програмыг хаах"). Хаахад эцсийн дүнг JSON болгоод хавтсанд хуулна
  (минут тутам ч хуулдаг тул компьютерийг гэнэт унтраасан ч алдагдахгүй).

## Самбар (зөвхөн админ)

Админы компьютер дээр "Самбар" товч / tray → "Самбар (админ)" → админ нууц үг:

- **Ажилтнууд:** хэн одоо ажиллаж / гарсан / офлайн, одоогийн апп, ажилласан/гарсан хугацаа, ирсэн–явсан цаг,
  өдрийн явц (ногоон = ажилласан, улаан = гарсан). Мөр дээр дарвал дэлгэрэнгүй: цагийн шугам, апп тус бүр, гарсан үеүд.
- **7 хоног:** хүн бүрийн өдөр бүрийн ажилласан цаг.
- **Түр зогсолт (N):** ажилтнуудын "Зогсоох" дарахдаа бичсэн шалтгаан (сүүлийн 7 хоног), хүлээгдэж байгаа нь
  шараар эхэндээ. Сонгоод **✓ Зөвшөөрөх** → тэр хугацаа ажилласан цагт нэмэгдэж (цагийн шугам дээр цэнхэр),
  гарсан цагаас хасагдана; **✗ Татгалзах** → "гарсан" хэвээр. Хэд хэдийг зэрэг сонгож, шийдвэрээ дараа нь сольж
  болно. Дууссан зогсолтыг зөвшөөрөхөд тэр үеийн хугацаа хадгалагдана (дараа нь ажилтан сунгаж чадахгүй).
  Шалтгаан самбарт ажилтан зогсоосноос хойш ~3 секундэд, админы tray мэдэгдэл 15 секундэд ирнэ. **Шалтгаан
  ирэхгүй бол:** ажилтан болон админы програм хоёулаа **3.5.0+** байх ёстой (хуучин програм шалтгаан
  асуудаггүй / хадгалдаггүй) — доорх анхааруулгыг харна уу.
- **«⚠ Ажилтнуудад тараасан хувилбар…»** (дээд талд): таны exe ажилтнуудад тараасан `update\` дахь хувилбараас
  шинэ байна → **Ажилтнуудад тараах** дарвал энэ exe-г `update\`-д байршуулж, ажилтнуудын програм 30 минутын
  дотор өөрөө шинэчлэгдэнэ (`python build.py --publish`-тэй ижил). Хэрэглэгчид → Хувилбар баганад хуучин нь ⚠.
- **Хэрэглэгчид:** нэр засах, хэлтэс оноох, хаах. **🗑 Бүрмөсөн устгах** — ажлаас гарсан хүний бүх түүхийг устгаж, жагсаалтаас хасна; түүний програм цаашид өгөгдөл илгээхгүй (андуурвал "Устгасан хүмүүс…"-ээс сэргээнэ). **Хэлтэс**, **Тохиргоо** (ажилтнуудын
  компьютерт 10 минутын дотор хүчинтэй болно).
- **CSV хадгалах:** Excel-д нээнэ.

Хүснэгтэд мөн: **Хоцорсон**, **Бүтээмж %**, "+илүү цаг", "эрт явсан", "хаалттай NN мин" (ажлын цагаар програм
ажиллаагүй), ⚠ (сэжигтэй), **Ирээгүй**. Цагийн шугам дээр босоо зураас = ажлын цаг, цайвар = цайны цаг,
улбар шар = сэжигтэй үе. 7 хоногийн хүснэгтэд ирээгүй ажлын өдөр улаанаар.

## Хууран мэхлэлтээс хамгаалах

| Юуг илрүүлнэ | Хэрхэн | Үр дүн |
|---|---|---|
| Камерын өмнө **зураг / бичлэг** тавьсан | MiniFASNetV2 нүүрний дүрсийг зураг/дэлгэцийн хуурмаг эсэхээр шалгана; дээр нь эхний 30–60 секундэд, дараа 20–40 минут тутам санамсаргүй сумны чигт толгойгоо хоёр тийш эргүүлэх сорил өгнө. 3 дараалсан хуурамч таамаг эсвэл 25 секундэд сорил биелүүлээгүй бол сэжигтэй | Сорилын хугацаанд цаг тоолохгүй; сэжигтэй үед ⚠ тэмдэг, Telegram мэдэгдэл |
| Камерыг **таглаж** / наалт наасан | Кадр 30 сек бараг хар эсвэл нэг өнгөтэй | ⚠ "Камер таглагдсан", мэдэгдэл |
| **Өөр хүн** суулгаж ажиллуулах (админ царай танихыг асаасан бол) | Камерын өмнөх царайг ажилтны бүртгэлтэй 15 сек тутам харьцуулна; 3 минут (тохируулж болно) дараалан таарахгүй бол | Ажилласан цагт тооцохгүй (гар хөдөлсөн ч), ⚠ "Өөр хүн суусан", 👤 мэдэгдэл |
| Ажлын цагаар **програм хаасан** / компьютер унтраасан | Ирсэн–явсан хооронд програм ажиллаагүй үе | "хаалттай NN мин", мэдэгдэл |
| Компьютерийн **цагийн бүсийг** сольж хоцролтоо нуух | Програм Windows-ийн цагийн бүсийг ашиглахгүй — UTC + компанийн бүс (UTC+8) | Огт нөлөөлөхгүй |
| Компьютерийн **цагийг** ухрааж / урагшлуулж ирсэн–явсан цагаа худал болгох | Програм асахдаа цагаа аваад, дараа нь өөрөө тоолно (унтсан хугацааг оруулаад). Системийн цаг 2+ минут үсэрвэл шинэ цагийг авахгүй. Програмыг хаагаад цагаа ухрааж дахин асаасныг ч илрүүлнэ | Ирсэн/явсан цаг зөв хэвээр, ⚠ "Компьютерийн цагийг өөрчилсөн", 🕐 Telegram мэдэгдэл |
| Цагаа ухрааж **компьютерийг дахин ачаалах** | Програм админы компьютертэй холбогдох бүртээ цагаа түүнд тааруулна (админы компьютер = жишиг цаг) | Өнөөдрийн ирсэн цаг, үеүд зөв цаг руу засагдана, ⚠ + 🕐 "админы компьютерээс 51 мин хоцорч байсан" |
| Сүлжээгээ салгаж, буруу цагаар ажиллаад дараа нь холбогдох | Сервер ажилтан анх холбогдсон цагийг өөрөө бичнэ. Админы компьютер асаалттай байхад програмын "ирсэн цаг"-аас 15+ мин хойш холбогдсон бол | ⚠ "Цаг зөрүүтэй: компьютер 08:50, сервер 09:41", 🕐 мэдэгдэл |

Хязгаар: MiniFASNetV2 болон санамсаргүй сорил нь хэвлэмэл зураг, дэлгэцийн бичлэгээр хуурахыг илрүүлэхэд тусална. Гэхдээ камер, гэрэл, халдлагын төрлөөс хамаарч алдаж болох тул сорилд тааруулсан шууд удирдлагатай видео, 3D маск, виртуал камерын оролтыг бүрэн ялгана гэж батлахгүй.
Админы програм өөрийн цагийг 30 минут тутам интернэтийн цагтай харьцуулна (api.telegram.org, google.com,
cloudflare.com-ийн хариуны цаг — хоосон хүсэлт, мэдээлэл явуулахгүй). Админы компьютерийн цаг буруу байсан ч
ажилтнуудад зөв цагийг өгч, самбарын дээд талд "⚠ Энэ компьютерийн цаг N мин хоцорч байна" гэж анхааруулна.
Интернэтгүй бол админы компьютерийн цагаар ажиллана. 5 минутаас бага зөрүүг засах боловч ⚠ гэж тэмдэглэхгүй. Админы компьютертэй огт холбогдоогүй
өдрүүдийн (жишээ нь гэрээсээ) цагийг засах боломжгүй — "Цаг зөрүүтэй" нь сүлжээ тасарсанаас ч үүсч болно.
Бүдэг гэрэлд камерын шуугиан ихсэх тул зураг илрэхгүй байж болно (гэхдээ амьд хүнийг буруу тэмдэглэхгүй).

## Telegram мэдэгдэл

Админы компьютер дээрх програм **5 минут тутам** хавтсыг шалгаад Telegram групп руу бичнэ:

## Автомат шинэчлэл

Кодыг өөрчилсний дараа админы компьютер дээр:
```
python build.py --publish
```
Шинэ exe `C:\AjliinButeemjData\update\`-д байршина. Ажилтнуудын програм **30 минутын дотор** (эсвэл дараагийн
удаа асахад) өөрөө татаж (SHA-256 шалгана), солиод дахин эхэлнэ — дахин тараах шаардлагагүй.
`--publish`-гүй бүтээсэн бол (зөвхөн `dist\`-д) ажилтнууд хуучин хувилбар дээрээ үлдэнэ — тэр exe-г ажиллуулаад
самбарын **Ажилтнуудад тараах** товчоор тарааж болно.

- Шинэчлэх бүрт `worktracker/__init__.py` дахь `__version__`-ийг нэмэгдүүлнэ (жишээ: `3.2.0` → `3.2.1`).
- Ажилтнууд шинэ хувилбарыг серверээс зөвхөн **татна** — хэн нэгэн хортой exe тавьж тараах боломжгүй.
- 3.1.x хувилбартай хүмүүс шинэчлэлээ `C:\AjliinButeemjShare` (зөвхөн уншигдах хуваалцсан хавтас) -аас авна.
  Самбар → Хэрэглэгчид → **Хувилбар** баганад бүгд 3.2+ болсон бол энэ хавтас хэрэггүй.
- 3.1.0-ээс өмнөх exe-тэй хүмүүст шинэ exe-г **нэг удаа** гараар өгнө.
- Өөрийн програмыг `dist\`-ээс биш, тусдаа хавтсанд хуулж ажиллуулаарай (ажиллаж байхад `dist\`-ийн exe-г
  дахин бүтээж чадахгүй).
- Унтраах: `config.json` → `"auto_update": false`. `.exe`-г бичих эрхтэй хавтаст байлгана
  (жишээ нь `C:\Users\<нэр>\AjliinButeemj\`), `Program Files`-д биш.

## Хөгжүүлэлт (Python-оор ажиллуулах)

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python main.py                # цонхтой
python main.py --background   # цонхгүй, зөвхөн tray
python main.py --admin-setup  # энэ компьютерийг админых болгох
python main.py --no-gui       # терминал дээр
python main.py --camera-test  # камер, царай илрүүлэлт/танилтыг харах (E — царай бүртгэх, юу ч хадгалахгүй)
python main.py --selftest     # камер нээхгүйгээр бүх модулийг шалгах
python main.py --report       # өнөөдрийн HTML тайлан
```

Python-оор ажиллуулахад өгөгдөл `data/` хавтаст хадгалагдана.

## .exe бүтээх

PyInstaller нь зөвхөн Windows дээр бүтээнэ.

- `python build.py` → `dist\AjliinButeemj.exe` (нэг файл)
- `python build.py --clean` — цэвэр бүтээх, `--selftest` — бүтээсний дараа шалгах, `--publish` — ажилтнуудыг автоматаар шинэчлэх.

`hub.json` төслийн хавтаст байвал програмд багцлагдана. Эсвэл `.exe`-ийн хажууд `hub.json` тавьж тарааж болно.

## Нэмэлт: имэйл / Telegram өдрийн тайлан

`config.example.json`-г `config.json` нэрээр `.exe`-ийн хажууд тавьж `email` / `telegram` хэсгийг бөглөвөл
ажилтан бүрийн өдрийн тайланг илгээнэ. Анхаар: `config.json` дахь нууц үгийг ажилтан харах боломжтой.

## Анхаарах зүйлс

- **Ажилтанд мэдэгдэх:** камер ашигладаг хяналтын програмыг ажилтанд урьдчилан мэдэгдэж, зөвшөөрөл авах
  (хөдөлмөрийн гэрээ / дотоод журамд тусгах) шаардлагатай. Програм ажиллаж байхад камерын гэрэл асаалттай,
  төлөв нь tray дүрс болон цонхон дээр харагдана.
- **Царай таних** (анхдагчаар унтраалттай; Самбар → Тохиргоо → Илрүүлэлт → "Царай таних"):
  - Асаахад ажилтан бүрийн програм **зөвшөөрөл асууна**. Зөвшөөрвөл камер руу 5 сек харж бүртгүүлнэ, татгалзвал
    самбарын Хэрэглэгчид табд "татгалзсан" гэж харагдана.
  - Хадгалах зүйл нь царайн **зураг биш**, 128 тооноос бүрдэх "царайн хээ" (5 ширхэг). Түүнээс зураг сэргээх
    боломжгүй. Зөвхөн админы компьютерт (`people\<uid>\face.json`) хадгалагдаж, ажилтныг устгахад хамт устна.
  - Биометрийн мэдээлэл тул Хувь хүний мэдээлэл хамгаалах тухай хуулийн дагуу ажилтанд урьдчилан мэдэгдэж,
    дотоод журамд тусгана.
  - Ажилтан өөр хүний царайгаар дахин бүртгүүлж чадахгүй: дахин бүртгүүлэхэд админ "Царай шинэчлэх" дарна.
  - Бүдэг гэрэл, хажуу тийш харах үед андуурч болох тул нэг удаа биш, 3+ минут дараалан таарахгүй бол л тэмдэглэнэ.
- **Хамгаалалт:** ажилтан бүр анх холбогдохдоо хувийн түлхүүр авдаг (`%APPDATA%\AjliinButeemj\device.json`),
  сервер хүсэлт бүрийн гарын үсгийг шалгаж зөвхөн **өөрийнх нь** өгөгдлийг бичихийг зөвшөөрнө. exe-г задалсан ч
  бусдын цагийг харах, засах боломжгүй. Үлдэх эрсдэл: ажилтан **өөрийнхөө** цагийг програмаа задалж хуурамчаар
  илгээх боломж (цагийг тухайн компьютер тоолдог тул бүрэн хаах аргагүй) — ажлын журамд тусгана.
- Ажилтан програмаа дахин суулгасан / компьютер сольсон бол "түлхүүр таарахгүй" гэж гарна → Самбар → Хэрэглэгчид →
  **Түлхүүр шинэчлэх**.
- Ажилтан програмыг бүрэн хааж болно (tray → хаах) — самбарт **Офлайн**, "хаалттай NN мин" харагдаж, ажлын цагаар
  бол Telegram мэдэгдэл очно.
