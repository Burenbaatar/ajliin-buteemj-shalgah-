# Ажлын бүтээмж

Нэг програм (Windows `.exe` / macOS `.app`). Хүн бүр **нэвтэрч орно**, програм **камераар** тухайн хүн
компьютерийн өмнө байгаа эсэхийг шалгаж, байхад цаг тоолж, гарахад зогсооно. Апп тус бүр дээр хэдэн минут
ажилласныг бүртгэнэ. Менежер, админ програм доторх **самбараас** бусдыг шууд харна.

- Дэлгэц бичихгүй, дэлгэцийн зураг авахгүй, камерын зураг хадгалахгүй (кадр санах ойд шалгагдаад устана).
- Цонхны гарчиг биш, зөвхөн **аппын нэр**ийг бүртгэнэ ("Google Chrome", "Microsoft Excel").
- Өгөгдөл Supabase (үнэгүй үүлэн Postgres) дээр. Интернэт тасарвал компьютер дээрээ хадгалаад дараа нь нөхөж илгээнэ.

## Гурван эрх

| Эрх | Юу хийх вэ |
|---|---|
| **Ажилтан** | Нэвтрэхэд цаг бүртгэл автоматаар эхэлнэ. "Миний түүх"-ээс зөвхөн өөрийгөө харна |
| **Менежер** | Цаг бүртгэл + **Самбар**: өөрийн **хэлтсийн** ажилтнуудын одоогийн төлөв, өдрийн явц, апп, 7 хоног |
| **Админ** | Цаг бүртгэл + бүх хүнийг харна + **Хэрэглэгчид** (эрх, хэлтэс оноох, хаах), **Хэлтэс**, **Тохиргоо** |

- **Анх бүртгүүлсэн хүн автоматаар Админ болно.**
- Бусад хүн програмаас **"Шинээр бүртгүүлэх"** → "Хүлээгдэж буй" төлөвт орно → Админ эрх, хэлтсийг нь оноомогц
  тэр хүний програм автоматаар цаг бүртгэж эхэлнэ.
- Хэн юуг харах вэ гэдгийг **сервер** (Postgres RLS) шийднэ — програмыг өөрчилсөн ч бусдын мэдээллийг харж чадахгүй.

## Хэрхэн ажилладаг вэ

| Хэсэг | Технологи |
|---|---|
| Хүн илрүүлэх | OpenCV + YuNet царай илрүүлэх загвар, секунд тутам |
| Идэвхтэй апп | Windows: pywin32 + psutil · macOS: pyobjc (AppKit) |
| Гар/хулгана | Windows: `GetLastInputInfo` · macOS: Quartz |
| Компьютер дээр | SQLite (хэрэглэгч бүр тусдаа) |
| Сервер | Supabase: Auth (нэвтрэх) + Postgres + RLS (эрх) |
| Цонх, самбар | Tkinter |
| Суулгах | PyInstaller → `AjliinButeemj.exe` / `AjliinButeemj.app` |

Төлөв тодорхойлох дүрэм:

1. Камерт царай харагдаж байвал → **Ажиллаж байна** (тухайн үеийн идэвхтэй аппад цаг нэмнэ).
2. Царай харагдахгүй болбол 20 сек хүлээнэ (админ өөрчилж болно). Энэ хугацаанд эргэж харвал алдагдалгүй.
3. Түүнээс удвал → **Ажлаас гарсан**. Тэр 20 секунд ч "гарсан" хугацаанд орно.
4. Гар/хулгана хөдөлж байвал (доош харж бичиж байгаа гэх мэт) хүн байна гэж үзнэ.
5. Дэлгэц түгжигдвэл (Win+L, ⌃⌘Q) шууд **Ажлаас гарсан**.
6. Камер олдохгүй бол гар/хулганы хөдөлгөөнөөр л шалгана (5 мин хөдлөхгүй бол гарсан).
7. Компьютер унтсан хугацааг тоолохгүй. Програм хаагдвал самбарт **Офлайн** болно.

## Нэг удаагийн тохиргоо (админ, ~15 минут)

1. **Supabase төсөл:** <https://supabase.com> → New project. Region: *Northeast Asia (Seoul)* эсвэл *Tokyo*.
2. **Өргөтгөл (Telegram мэдэгдэлд):** Database → Extensions → **pg_cron** болон **pg_net**-ийг асаана.
3. **Схем:** SQL Editor → New query → [`supabase/schema.sql`](supabase/schema.sql)-ийг бүхэлд нь хуулж → **Run**.
   `OK — схем бэлэн` гэж гарна. (Өргөтгөлгүй бол "pg_cron асаагүй" гэж сануулна — Telegram-аас бусад нь ажиллана.)
4. **Имэйл баталгаажуулалтыг унтраах:** Authentication → Sign In / Providers → Email → **Confirm email**-ийг унтраана.
   (Админ хүн бүрийг гараар баталгаажуулдаг тул хэрэггүй. Supabase-ийн үнэгүй имэйл цагт хэдхэн л явуулдаг.)
5. **Түлхүүр:** Project Settings → API Keys → **Project URL** болон **Publishable key** (эсвэл *Legacy* табын `anon` key).
   Энэ хоёр нууц биш (эрхийг сервер шалгадаг).
6. **`server.json`** — төслийн үндсэн хавтаст үүсгэнэ ([`server.example.json`](server.example.json)-ийг хуулж):
   ```json
   { "supabase_url": "https://xxxx.supabase.co", "supabase_key": "sb_publishable_..." }
   ```
   Бүтээхэд энэ файл програмд **багцлагдана** → ажилтан юу ч тохируулахгүй, шууд нэвтрэх цонх гарна.
   (`server.json`-гүй бүтээсэн бол програм анх нээхэд URL/key асууна.)
7. **Бүтээх:** `git tag v2.1.0 && git push origin v2.1.0` → GitHub Actions бүтээж **Release** үүсгэнэ
   (эсвэл Actions → build → Run workflow, эсвэл `build_windows.bat` / `build_mac.sh`).
8. **Админ болох:** програмаа нээж **хамгийн түрүүнд** "Шинээр бүртгүүлэх" → та Админ боллоо.
9. **Хэлтэс, хуваарь:** Самбар → Хэлтэс → "Борлуулалт", "Нягтлан"…; Самбар → Тохиргоо → ажлын цаг, цайны цаг,
   ажлын өдрүүд, бүтээмжтэй/бүтээмжгүй апп, Telegram.
10. **Ажилтнуудад тараах:** `.exe`/`.app`-г өгнө → тэд бүртгүүлнэ → Самбар → **Хэрэглэгчид** (шараар гарна) →
   эрх, хэлтсийг сонгоод **Хадгалах**.
11. Бүгд бүртгүүлсний дараа (заавал биш) Supabase → Authentication → *Allow new users to sign up* унтрааж болно.

## Ажилтны компьютерт суулгах

1. **Windows:** `AjliinButeemj.exe`-г нээнэ. Гарын үсэггүй .exe тул SmartScreen "More info → Run anyway" гэж асууж болно.
   Settings → Privacy & security → Camera → "Let desktop apps access your camera" асаалттай байх.
2. **macOS:** zip-ийг задлаад, анх нээхэд баруун товч → **Open** (гарын үсэггүй апп). Камерын зөвшөөрөл → **Allow**.
   Андуурч татгалзсан бол System Settings → Privacy & Security → Camera.
3. Нэг удаа нэвтэрсний дараа програм нэвтрэлтийг санана. Компьютер асах бүрт **автоматаар** эхэлж, цаг бүртгэнэ.
4. Шалгах: `AjliinButeemj.exe --selftest` (Windows: лог файлд) /
   `AjliinButeemj.app/Contents/MacOS/AjliinButeemj --selftest`.

Компьютер дээрх өгөгдөл, лог:

- Windows: `%APPDATA%\AjliinButeemj\` (`users\<id>\worktime.db`, `session.json`, `app.log`)
- macOS: `~/Library/Application Support/AjliinButeemj/`

## Самбар

Програмын **"Самбар"** (менежер/админ) эсвэл **"Миний түүх"** (ажилтан) товч:

- **Ажилтнууд:** хэн одоо ажиллаж / гарсан / офлайн, одоогийн апп, ажилласан/гарсан хугацаа, ирсэн–явсан цаг,
  өдрийн явц (ногоон = ажилласан, улаан = гарсан). Мөр дээр дарвал дэлгэрэнгүй: цагийн шугам, апп тус бүр, гарсан үеүд.
- **7 хоног:** хүн бүрийн өдөр бүрийн ажилласан цаг.
- **CSV хадгалах:** Excel-д нээнэ.
- Админд: **Хэрэглэгчид**, **Хэлтэс**, **Тохиргоо** (гарсан гэж үзэх хугацаа, гар/хулганыг тооцох эсэх г.м. —
  бүх компьютерт 10 минутын дотор хүчинтэй болно).

Хүснэгтэд мөн: **Хоцорсон**, **Бүтээмж %**, "+илүү цаг", "эрт явсан", "хаалттай NN мин" (ажлын цагаар програм
ажиллаагүй), ⚠ (сэжигтэй), **Ирээгүй**. Цагийн шугам дээр босоо зураас = ажлын цаг, цайвар = цайны цаг,
улбар шар = сэжигтэй үе. 7 хоногийн хүснэгтэд ирээгүй ажлын өдөр улаанаар.

**Утаснаас харах (заавал биш):** [`docs/index.html`](docs/index.html) нь ижил самбарын вэб хувилбар
(ижил нэвтрэлт, ижил эрх). GitHub repo → Settings → Pages → `main` / `/docs` → Save →
`https://<github-нэр>.github.io/<repo>/`. `docs/index.html` доторх `DEFAULT_URL`/`DEFAULT_KEY`-г бөглөвөл асуухгүй.
Жишээ өгөгдлөөр үзэх: хаягийн ард `?demo`.

## Хууран мэхлэлтээс хамгаалах

| Юуг илрүүлнэ | Хэрхэн | Үр дүн |
|---|---|---|
| Камерын өмнө **зураг** тавьсан | Нүүрний хэсэг 2 минут (тохируулж болно) огт хөдлөхгүй бол — амьд хүн нүдээ ирмэх, бага зэрэг хөдлөхөд өөрчлөгддөг | Ажилласан цагт тооцохгүй, ⚠ "Хөдөлгөөнгүй царай", Telegram мэдэгдэл |
| Камерыг **таглаж** / наалт наасан | Кадр 30 сек бараг хар эсвэл нэг өнгөтэй | ⚠ "Камер таглагдсан", мэдэгдэл |
| Ажлын цагаар **програм хаасан** / компьютер унтраасан | Ирсэн–явсан хооронд програм ажиллаагүй үе | "хаалттай NN мин", мэдэгдэл |

Хязгаар: дэлгэц/утсан дээр **видео** тоглуулах, гарт **барьж хөдөлгөж** буй зургийг энэ аргаар ялгахгүй.
Бүдэг гэрэлд камерын шуугиан ихсэх тул зураг илрэхгүй байж болно (гэхдээ амьд хүнийг буруу тэмдэглэхгүй).

## Telegram мэдэгдэл

Сервер (Supabase pg_cron) **5 минут тутам** шалгаад менежерийн Telegram групп руу бичнэ — хэний ч компьютер асаалттай байх шаардлагагүй:

- ⏰ "Бат 09:30 болтол ирээгүй байна" · 🚶 "Сараа 14:05-с хойш (40+ минут) алга" · ⚠️ "…програм 15:10-с хойш хаалттай"
  · 📷 "…камер таглагдсан" · 🖼 "…хөдөлгөөнгүй царай (зураг?)". Нэг үйл явдлыг нэг л удаа.

Тохируулах: @BotFather → `/newbot` → токен. Ботыг Telegram групп(үүд)-т нэмээд группт нэг мессеж бичнэ.
Програм → Самбар → **Тохиргоо → Telegram**: токен, "Чат олох" → админы чат; **Хэлтэс** табаас хэлтэс бүрийн чат.
Босго (ирээгүй/гарсан/хаалттай минут) мөн тэнд. Supabase дээр pg_cron, pg_net асаалттай байх.

## Нууц үг мартвал

- **Админ:** Самбар → Хэрэглэгчид → тухайн хүн → **Түр нууц үг тавих** (имэйл хэрэггүй). Тэр хүн нэвтрээд
  "Нууц үг солих"-оор сольж болно.
- **Өөрөө (имэйлээр код):** нэвтрэх цонх → "Нууц үг мартсан?" → имэйл рүү 6 оронтой код. Үүнд админ нэг удаа:
  1. Supabase → Authentication → Emails → SMTP Settings → өөрийн SMTP (Gmail App Password, Resend, Brevo г.м.).
     Supabase-ийн өгөгдмөл имэйл зөвхөн танай Supabase багийн гишүүдэд илгээдэг.
  2. Authentication → Emails → Templates → **Reset Password**: `{{ .Token }}`-г загварт нэмнэ
     (жишээ: `<p>Нууц үг сэргээх код: <b>{{ .Token }}</b></p>`).

## Арын горим (tray) ба автомат шинэчлэл

- Цонхыг ✕ хаахад програм **арын горимд** үргэлжилнэ. Windows: tray дүрс (ногоон/улаан) → давхар дарж нээнэ,
  баруун товч → "Програмыг хаах". macOS: Dock дүрс дээр дарж нээнэ, бүрэн хаах бол ⌘Q.
  Програмыг дахин нээх гэж оролдвол ажиллаж байгаа цонх нь гарч ирнэ.
- `v*` tag push хийхэд GitHub Release үүснэ. Програм эхлэх бүрт болон 6 цаг тутам шинэ хувилбар шалгаж,
  татаж (SHA-256 шалгана), солиод дахин нээгдэнэ. Унтраах: `config.json` → `"auto_update": false`.
- Анхаар: `.exe`-г бичих эрхтэй хавтаст байлгана (жишээ нь `C:\Users\<нэр>\AjliinButeemj\`), `Program Files`-д биш.
  macOS дээр гарын үсэггүй апп тул шинэчлэлийн дараа камерын зөвшөөрлийг дахин асууж магадгүй.

## Хөгжүүлэлт (Python-оор ажиллуулах)

```bash
python3 -m venv .venv
# macOS:   source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt

python main.py                # цонхтой (нэвтрэх → цаг бүртгэл)
python main.py --no-gui       # терминал дээр (имэйл/нууц үг асууна)
python main.py --camera-test  # камер, царай илрүүлэлтийг харах (юу ч хадгалахгүй)
python main.py --selftest     # камер нээхгүйгээр бүх модулийг шалгах
python main.py --report       # өнөөдрийн HTML тайлан
```

Python-оор ажиллуулахад өгөгдөл `data/` хавтаст хадгалагдана.

## Нэмэлт: имэйл / Telegram тайлан

Самбараас гадна өдрийн тайланг имэйл эсвэл Telegram-аар илгээж болно. `config.example.json`-г `config.json`
нэрээр `.exe`/`.app`-ийн хажууд тавьж `email` / `telegram` хэсгийг бөглөнө (Gmail App Password, Telegram
@BotFather токен + chat_id). Илгээх цагийг админ самбарын Тохиргооноос өөрчилнө.
Анхаар: `config.json` дахь нууц үгийг ажилтан харах боломжтой тул тусдаа хаяг ашиглана уу.

## .exe / .app бүтээх (PyInstaller)

PyInstaller нь **тухайн үйлдлийн систем дээрээ** л бүтээдэг: `.exe`-г Windows дээр, `.app`-г Mac дээр.

- **Windows:** `build_windows.bat` → `dist\AjliinButeemj.exe` (нэг файл)
- **macOS:** `./build_mac.sh` → `dist/AjliinButeemj.app` + `dist/AjliinButeemj-mac.zip`
- **Windows компьютергүй бол:** GitHub → **Actions → build → Run workflow** (эсвэл `v*` tag push).
  Windows болон Mac хоёуланг бүтээж, туршаад Artifacts хэсэгт гаргана.

`server.json` төслийн үндсэн хавтаст байвал програмд автоматаар багцлагдана. Ажилтанд Python хэрэггүй.

## Анхаарах зүйлс

- **Ажилтанд мэдэгдэх:** камер ашигладаг хяналтын програмыг ажилтанд урьдчилан мэдэгдэж, зөвшөөрөл авах
  (хөдөлмөрийн гэрээ / дотоод журамд тусгах) шаардлагатай. Програм ажиллаж байхад камерын гэрэл асаалттай,
  төлөв нь цонхон дээр үргэлж харагдана.
- Ажилтан програмыг бүрэн хааж (tray → хаах), эсвэл "Гарах" дарж болно — тэр үед самбарт **Офлайн**,
  "хаалттай NN мин" харагдаж, ажлын цагаар бол Telegram мэдэгдэл очно.
- Supabase-ийн үнэгүй багц (500 MB) хангалттай: 20 хүн жилд ~10 MB. 7 хоног огт хэрэглээгүй төслийг
  Supabase түр зогсоодог ч ажлын өдрүүдэд програм тасралтгүй илгээдэг тул асуудалгүй.
