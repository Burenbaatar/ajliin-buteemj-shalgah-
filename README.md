# Ажлын бүтээмж

Нэг програм (Windows `.exe` / macOS `.app`). Компьютер асахад **арын горимд** (зөвхөн tray дүрс) эхэлж,
**камераар** ажилтан компьютерийн өмнө байгаа эсэхийг шалгаж, байхад цаг тоолж, гарахад зогсооно. Апп тус бүр
дээр хэдэн минут ажилласныг бүртгэнэ. Өгөгдлөө **JSON** болгоод **админы хуваалцсан хавтас** руу хуулна —
админ самбараас бүх ажилтныг харна.

- **Сервер, IP, нэвтрэлт хэрэггүй.** Ажилтныг Windows хэрэглэгч + компьютерийн нэрээр автоматаар таньна
  (анх нээхэд нэрээ л нэг удаа бичнэ). Хавтасны хаяг (`\\ADMIN-PC\AjliinButeemj`) нь IP биш, компьютерийн нэр.
- **Зөвхөн Python**, SQL ашиглахгүй. Бүх өгөгдөл энгийн JSON файл.
- Дэлгэц бичихгүй, дэлгэцийн зураг авахгүй, камерын зураг хадгалахгүй (кадр санах ойд шалгагдаад устана).
- Цонхны гарчиг биш, зөвхөн **аппын нэр**ийг бүртгэнэ ("Google Chrome", "Microsoft Excel").

## Хэрхэн ажилладаг вэ

```
 Ажилтны компьютер (tray)                       Админы компьютер
 ─────────────────────────                      ─────────────────────────────────────────
 камер + апп → цаг тоолно                       \\ADMIN-PC\AjliinButeemj\
 → өөрийн компьютерт JSON                         company.json   (тохиргоо, хэлтэс — админ)
 → минут тутам + хаагдахад ────── хуулна ──────►  people\<хэрэглэгч@компьютер>\
                                                     profile.json, live.json, days\<өдөр>.json
 ◄──── 10 мин тутам тохиргоо уншина ─────────── Самбар (админ нууц үгээр) · Telegram мэдэгдэл
```

| Хэсэг | Технологи |
|---|---|
| Хүн илрүүлэх | OpenCV + YuNet царай илрүүлэх загвар, секунд тутам |
| Идэвхтэй апп | Windows: pywin32 + psutil · macOS: pyobjc (AppKit) |
| Гар/хулгана | Windows: `GetLastInputInfo` · macOS: Quartz |
| Компьютер дээр | JSON файлууд (өдөр бүр нэг файл) |
| Админ руу | Хуваалцсан хавтас (Windows file sharing / SMB) — JSON файлууд |
| Цонх, tray, самбар | Tkinter + pystray |
| Суулгах | PyInstaller → `AjliinButeemj.exe` / `AjliinButeemj.app` |

- Компьютер бүр **зөвхөн өөрийн** `people\<хэрэглэгч@компьютер>\` хавтсанд бичнэ — хоорондоо зөрчилдөхгүй.
- Админы компьютер унтарсан / сүлжээ тасарсан үед өгөгдөл ажилтны компьютерт хадгалагдсаар байж,
  холбогдмогц сүүлийн 7 хоногийг **нөхөж** хуулна.

Төлөв тодорхойлох дүрэм:

1. Камерт царай харагдаж байвал → **Ажиллаж байна** (тухайн үеийн идэвхтэй аппад цаг нэмнэ).
2. Царай харагдахгүй болбол 20 сек хүлээнэ (админ өөрчилж болно). Энэ хугацаанд эргэж харвал алдагдалгүй.
3. Түүнээс удвал → **Ажлаас гарсан**. Тэр 20 секунд ч "гарсан" хугацаанд орно.
4. Гар/хулгана хөдөлж байвал (доош харж бичиж байгаа гэх мэт) хүн байна гэж үзнэ.
5. Дэлгэц түгжигдвэл (Win+L, ⌃⌘Q) шууд **Ажлаас гарсан**.
6. Камер олдохгүй бол гар/хулганы хөдөлгөөнөөр л шалгана (5 мин хөдлөхгүй бол гарсан).
7. Компьютер унтсан хугацааг тоолохгүй. Програм хаагдвал самбарт **Офлайн** болно.

## Нэг удаагийн тохиргоо (админ, ~5 минут)

1. **Админы компьютер:** оффисын, ажлын цагаар **асаалттай** байдаг компьютер (ажилтнуудтай нэг сүлжээнд).
   Python 3.9+ суулгана (<https://www.python.org/downloads/>, "Add python.exe to PATH" чагтлах).
2. **Админ тохиргоо** — төслийн хавтаст:
   ```
   python main.py --admin-setup
   ```
   Windows админ эрх (UAC) асууна. Автоматаар:
   - админ нууц үг тавина (самбар нээхэд асууна);
   - `C:\AjliinButeemjData` хавтсыг `\\<энэ компьютер>\AjliinButeemj` нэрээр хуваалцана;
   - ажилтны програмууд холбогдох тусгай хэрэглэгч (`ajliinbuteemj`, нэвтрэх дэлгэцэнд харагдахгүй) үүсгэнэ;
   - Windows firewall-д "File and Printer Sharing"-ийг (зөвхөн Private сүлжээнд) асаана;
   - `share.json` бичнэ (хавтасны хаяг + тусгай хэрэглэгчийн нууц үг).
3. **Бүтээх:** `python build.py` → `dist\AjliinButeemj.exe`. `share.json` exe дотор **багцлагдана** — ажилтан юу ч
   тохируулахгүй.
4. **Ажилтнуудад тараах:** `AjliinButeemj.exe`-г өгнө. Анх нээхэд нэрээ бичнэ — тэгээд л болоо.
5. **Хэлтэс, хуваарь:** Самбар → Хэлтэс → "Борлуулалт", "Нягтлан"…; Хэрэглэгчид (шинэ хүн шараар) → хэлтэс оноох;
   Тохиргоо → ажлын цаг, цайны цаг, ажлын өдрүүд, бүтээмжтэй/бүтээмжгүй апп, Telegram.

Админы компьютерийн сүлжээ **Private** (Settings → Network → Properties → Private network) байх ёстой.
`C:\AjliinButeemjData`-г тогтмол нөөцлөөрэй (20 хүн жилд ~10–20 MB).

## Ажилтны компьютерт

1. **Windows:** `AjliinButeemj.exe`-г нээнэ. Гарын үсэггүй .exe тул SmartScreen "More info → Run anyway" гэж асууж болно.
   Settings → Privacy & security → Camera → "Let desktop apps access your camera" асаалттай байх.
2. **macOS:** zip-ийг задлаад, анх нээхэд баруун товч → **Open** (гарын үсэггүй апп). Камерын зөвшөөрөл → **Allow**.
   Хавтсыг `mount_smbfs`-ээр автоматаар холбоно.
3. Анх нээхэд нэрээ бичнэ. Дараа нь компьютер асах бүрт **цонхгүйгээр** (зөвхөн tray дүрс) эхэлж цаг бүртгэнэ.
4. Шалгах: `AjliinButeemj.exe --selftest` (Windows: лог файлд) — "Админы хавтас: … холбогдсон" гэж гарна.

Компьютер дээрх өгөгдөл, лог: Windows `%APPDATA%\AjliinButeemj\` · macOS `~/Library/Application Support/AjliinButeemj/`

## Tray (арын горим)

- Компьютер асахад програм `--background` горимд эхэлнэ: цонх гарахгүй, зөвхөн tray дүрс (ногоон = ажиллаж байна,
  улаан = гарсан).
- Tray дүрс → давхар дарж цонхыг нээнэ · баруун товч → "⏸ Зогсоох" · "Самбар (админ)" (админы компьютер дээр) ·
  "Програмыг хаах".
- **⏸ Зогсоох / ▶ Үргэлжлүүлэх** (цонх болон tray): цаг тоолохыг гараар зогсооно (шар өнгө). Зогссон хугацаа
  "гарсан"-д тооцогдоно — ажилласан цаг нэмэгдэхгүй. Самбарт "⏸ зогсоосон" гэж харагдана.
- Цонхыг ✕ хаахад дахин tray руу нуугдана. Програмыг **бүрэн хаах**: цонхны доод талын улаан **Програмаас гарах** товч (эсвэл tray → "Програмыг хаах"). Хаахад эцсийн дүнг JSON болгоод хавтсанд хуулна
  (минут тутам ч хуулдаг тул компьютерийг гэнэт унтраасан ч алдагдахгүй).
- macOS: Dock дүрс дээр дарж нээнэ, бүрэн хаах бол ⌘Q.

## Самбар (зөвхөн админ)

Админы компьютер дээр "Самбар" товч / tray → "Самбар (админ)" → админ нууц үг:

- **Ажилтнууд:** хэн одоо ажиллаж / гарсан / офлайн, одоогийн апп, ажилласан/гарсан хугацаа, ирсэн–явсан цаг,
  өдрийн явц (ногоон = ажилласан, улаан = гарсан). Мөр дээр дарвал дэлгэрэнгүй: цагийн шугам, апп тус бүр, гарсан үеүд.
- **7 хоног:** хүн бүрийн өдөр бүрийн ажилласан цаг.
- **Хэрэглэгчид:** нэр засах, хэлтэс оноох, хаах. **🗑 Бүрмөсөн устгах** — ажлаас гарсан хүний бүх түүхийг устгаж, жагсаалтаас хасна; түүний програм цаашид өгөгдөл илгээхгүй (андуурвал "Устгасан хүмүүс…"-ээс сэргээнэ). **Хэлтэс**, **Тохиргоо** (ажилтнуудын
  компьютерт 10 минутын дотор хүчинтэй болно).
- **CSV хадгалах:** Excel-д нээнэ.

Хүснэгтэд мөн: **Хоцорсон**, **Бүтээмж %**, "+илүү цаг", "эрт явсан", "хаалттай NN мин" (ажлын цагаар програм
ажиллаагүй), ⚠ (сэжигтэй), **Ирээгүй**. Цагийн шугам дээр босоо зураас = ажлын цаг, цайвар = цайны цаг,
улбар шар = сэжигтэй үе. 7 хоногийн хүснэгтэд ирээгүй ажлын өдөр улаанаар.

## Хууран мэхлэлтээс хамгаалах

| Юуг илрүүлнэ | Хэрхэн | Үр дүн |
|---|---|---|
| Камерын өмнө **зураг** тавьсан | Нүүрний хэсэг 2 минут (тохируулж болно) огт хөдлөхгүй бол — амьд хүн нүдээ ирмэх, бага зэрэг хөдлөхөд өөрчлөгддөг | Ажилласан цагт тооцохгүй, ⚠ "Хөдөлгөөнгүй царай", Telegram мэдэгдэл |
| Камерыг **таглаж** / наалт наасан | Кадр 30 сек бараг хар эсвэл нэг өнгөтэй | ⚠ "Камер таглагдсан", мэдэгдэл |
| Ажлын цагаар **програм хаасан** / компьютер унтраасан | Ирсэн–явсан хооронд програм ажиллаагүй үе | "хаалттай NN мин", мэдэгдэл |

Хязгаар: дэлгэц/утсан дээр **видео** тоглуулах, гарт **барьж хөдөлгөж** буй зургийг энэ аргаар ялгахгүй.
Бүдэг гэрэлд камерын шуугиан ихсэх тул зураг илрэхгүй байж болно (гэхдээ амьд хүнийг буруу тэмдэглэхгүй).

## Telegram мэдэгдэл

Админы компьютер дээрх програм **5 минут тутам** хавтсыг шалгаад Telegram групп руу бичнэ:

- ⏰ "Бат 09:30 болтол ирээгүй байна" · 🚶 "Сараа 14:05-с хойш (40+ минут) алга" · ⚠️ "…програм 15:10-с хойш хаалттай"
  · 📷 "…камер таглагдсан" · 🖼 "…хөдөлгөөнгүй царай (зураг?)". Нэг үйл явдлыг нэг л удаа.

Тохируулах: @BotFather → `/newbot` → токен. Ботыг Telegram групп(үүд)-т нэмээд группт нэг мессеж бичнэ.
Самбар → **Тохиргоо → Telegram**: токен, "Чат олох" → админы чат; **Хэлтэс** табаас хэлтэс бүрийн чат.
Токен зөвхөн админы компьютерт хадгалагдана (хавтсанд биш).

## Автомат шинэчлэл (админы хавтсаар)

Кодыг өөрчилсний дараа админы компьютер дээр:
```
python build.py --publish
```
Шинэ exe `C:\AjliinButeemjData\update\`-д байршина. Ажилтнуудын програм **30 минутын дотор** (эсвэл дараагийн
удаа асахад) өөрөө татаж (SHA-256 шалгана), солиод дахин эхэлнэ — дахин тараах шаардлагагүй.

- Шинэчлэх бүрт `worktracker/__init__.py` дахь `__version__`-ийг нэмэгдүүлнэ (жишээ: `3.1.0` → `3.1.1`).
- `update\` хавтсыг ажилтнууд зөвхөн **уншина** — хэн нэгэн хортой exe тавьж тараах боломжгүй.
- Энэ боломж 3.1.0-аас эхэлсэн: түүнээс өмнөх exe-тэй хүмүүст 3.1.0-г **нэг удаа** гараар өгнө.
- Өөрийн програмыг `dist\`-ээс биш, тусдаа хавтсанд хуулж ажиллуулаарай (ажиллаж байхад `dist\`-ийн exe-г
  дахин бүтээж чадахгүй).
- Унтраах: `config.json` → `"auto_update": false`. `.exe`-г бичих эрхтэй хавтаст байлгана
  (жишээ нь `C:\Users\<нэр>\AjliinButeemj\`), `Program Files`-д биш.

## Хөгжүүлэлт (Python-оор ажиллуулах)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS: source .venv/bin/activate
pip install -r requirements.txt

python main.py                # цонхтой
python main.py --background   # цонхгүй, зөвхөн tray
python main.py --admin-setup  # энэ компьютерийг админых болгох
python main.py --no-gui       # терминал дээр
python main.py --camera-test  # камер, царай илрүүлэлтийг харах (юу ч хадгалахгүй)
python main.py --selftest     # камер нээхгүйгээр бүх модулийг шалгах
python main.py --report       # өнөөдрийн HTML тайлан
```

Python-оор ажиллуулахад өгөгдөл `data/` хавтаст хадгалагдана.

## .exe / .app бүтээх

PyInstaller нь **тухайн үйлдлийн систем дээрээ** л бүтээдэг: `.exe`-г Windows дээр, `.app`-г Mac дээр.

- **Windows:** `python build.py` → `dist\AjliinButeemj.exe` (нэг файл, `.sha256`-тай)
- **macOS:** `python3 build.py` → `dist/AjliinButeemj.app` + `dist/AjliinButeemj-mac.zip`
- `python build.py --clean` — цэвэр бүтээх, `--selftest` — бүтээсний дараа шалгах, `--publish` — ажилтнуудыг автоматаар шинэчлэх.

`share.json` төслийн хавтаст байвал програмд багцлагдана. Эсвэл `.exe`-ийн хажууд `share.json` тавьж тарааж болно.

## Нэмэлт: имэйл / Telegram өдрийн тайлан

`config.example.json`-г `config.json` нэрээр `.exe`-ийн хажууд тавьж `email` / `telegram` хэсгийг бөглөвөл
ажилтан бүрийн өдрийн тайланг илгээнэ. Анхаар: `config.json` дахь нууц үгийг ажилтан харах боломжтой.

## Анхаарах зүйлс

- **Ажилтанд мэдэгдэх:** камер ашигладаг хяналтын програмыг ажилтанд урьдчилан мэдэгдэж, зөвшөөрөл авах
  (хөдөлмөрийн гэрээ / дотоод журамд тусгах) шаардлагатай. Програм ажиллаж байхад камерын гэрэл асаалттай,
  төлөв нь tray дүрс болон цонхон дээр харагдана.
- **Хамгаалалт:** бүх ажилтны програм хавтсанд нэг тусгай хэрэглэгчээр ханддаг тул техникийн мэдлэгтэй хүн
  `\\ADMIN-PC\AjliinButeemj`-г Explorer-оор нээж бусдын JSON-г уншиж, засаж чадна. Самбар зөвхөн админд
  нээгдэнэ, гэхдээ файлын түвшинд бүрэн хамгаалалт биш. `share.json`-д тэр хэрэглэгчийн нууц үг байдаг тул
  git-д оруулахгүй (`.gitignore`).
- Ажилтан програмыг бүрэн хааж болно (tray → хаах) — самбарт **Офлайн**, "хаалттай NN мин" харагдаж, ажлын цагаар
  бол Telegram мэдэгдэл очно.
