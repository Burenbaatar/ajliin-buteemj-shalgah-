# Ажилтны бүтээмж хянах систем

Python + Tkinter програм.
- **Ажилтны тал:** ажилтан нэр, кодоороо нэвтэрч, зөвшөөрөлтэйгээр хэмжилт эхлүүлнэ. Програм секунд тутам дараах зүйлсийг бүртгээд 5 секунд тутам админ руу илгээнэ:
  - урд талд ажиллаж байгаа цонх (програм + гарчиг, браузер бол хуудасны гарчиг)
  - хулгана аль цонхон дээр байгаа
  - нээлттэй байгаа бүх програм
  - гар, хулгана хөдөлж байгаа эсэх
  - камерын өмнө **амьд хүн** (зураг, бичлэг биш) сууж байгаа эсэх, тэр нь **бүртгэлтэй ажилтан өөрөө** мөн эсэх
- **Админы тал:** зураг дээрх шиг самбараар хэн ажиллаж байгаа, гарсан, офлайн байгааг шууд харна. Мөн ажилласан хугацаа, хоцролт, бүтээмж, өдрийн явцыг харна.
- **Өгөгдөл:** бүх өгөгдөл JSON файлд хадгалагдана.

**Шаардлага:** Windows 10/11, Python 3.10 ба түүнээс шинэ (3.12, 3.14 дээр шалгасан), камер (ажилтны компьютерт).

## Суулгах, ажиллуулах

```
python -m pip install -r requirements.txt
python main.py
```

## Хоёр эрх: админ ба ажилтан

Програм нээгдэхэд нэвтрэх цонх гарна.

| | Админ | Ажилтан |
|---|---|---|
| Нэвтрэх | нууц үгээр (анх оруулсан нууц үг хадгалагдана) | админы компьютерийн хаяг, өөрийн нэр, код |
| Табууд | Ажилтнууд, Түр зогсолт, 7 хоног, Хэрэглэгчид, Хэлтэс, Тохиргоо | Камер, Компьютерийн идэвх |
| Камер | ажилтны нүүрийг устгах («Нүүр устгах») | нэвтэрмэгц камер асна. Нүүрээ нэг удаа бүртгүүлнэ («Нүүр бүртгэх») |
| Өгөгдөл | бүх JSON файл зөвхөн админы компьютерт хадгалагдана | өөрт нь юу ч хадгалагдахгүй |

**Сервер:**
- Админ нэвтэрмэгц түүний компьютер JSON сервер болно (порт `5050`).
- Хэмжиж байгаа ажилтны програм 5 секунд тутам шууд төлөв болон сүүлд илгээснээс хойших өсөлтийг илгээнэ.
- Админ холбогдохгүй бол өсөлт хуримтлагдаж, 30 секундын дараа хамт илгээгдэнэ. Цонх гацахгүй.

**Тохиргоо:**
- **Админы компьютер:** анх асаахад Windows firewall асуувал «Allow» дарна. Админаар нэвтэрмэгц цонхны дээд талд «Ажилтнууд «Админы компьютер» талбарт: 192.168.x.x» гэж IP хаяг гарна. Бусад компьютер дээрх ажилтнууд тэр хаягийг бичнэ. `127.0.0.1` нь зөвхөн админы програмтай нэг компьютер дээр ажиллана.
- **Нэг сүлжээ:** админ, ажилтны компьютерууд нэг Wi-Fi эсвэл сүлжээнд байх ёстой. Wi-Fi нь Windows дээр «Public» байвал firewall холболтыг хааж болзошгүй. Энэ үед «Private» болгох эсвэл firewall-д «Public» сүлжээнд ч зөвшөөрөл өгнө.
- **Нэвтрэхгүй байвал:** алдааны мессеж шалтгааныг хэлнэ: бүртгэлгүй нэр, код буруу, код өгөөгүй, админ руу холбогдсонгүй.
- **Нэг компьютер дээр турших:** програмыг 2 удаа нээнэ. Эхнийхийг нь админаар нэвтрүүлнэ. Хоёр дахийг нь ажилтнаар `127.0.0.1` хаягаар нэвтрүүлнэ.

## Админы табууд

**Ажилтнууд** (5 секунд тутам шинэчлэгдэнэ)
- **Дээд талд 8 хавтан:** Хүн, Ажиллаж байна, Гарсан, Офлайн, Нийт ажилласан, Дундаж / хүн, Хоцорсон, Ирээгүй.
- **Хүснэгт:**

  | Багана | Утга |
  |---|---|
  | Ажилтан | нэр · компьютерийн нэр |
  | Одоо | ● Ажиллаж байна / Гарсан (түр зогсоосон шалтгаан эсвэл камерын шалтгаан, жишээ нь «камерт өөр хүн») / Офлайн / Ирээгүй, «дөнгөж сая». Ажилтны камер ажиллахгүй байвал «(камергүй)» нэмэгдэнэ — тэр үед хугацааг гар, хулганаар л тоолж байгаа, хэн сууж байгааг шалгаагүй |
  | Одоогийн апп | урд талын цонх, жишээ нь `chrome.exe - Lofi music - YouTube` |
  | Ажилласан, Гарсан | өнөөдрийн минут. «Ажилласан» нь камер ажилтныг өөрийг нь баталгаажуулсан үеийнх (камер ажиллахгүй бол гар, хулгана хөдөлсөн үеийнх), мөн админ зөвшөөрсөн түр зогсолт |
  | Ирсэн – Явсан | өнөөдрийн анхны болон сүүлийн цаг |
  | Хоцорсон | ажил эхлэх цаг + хүлцлээс хойш ирсэн бол «2ц 26м» |
  | Бүтээмж | ажилласан хугацаанаас бүтээмжгүй програм/сайт (анхдагч: YouTube, Facebook, Instagram) биш хэсгийн хувь |
  | Өдрийн явц | 08:00–20:00, 30 минут тутам: `█` ажилласан, `▒` гарсан, `·` байхгүй |
  | Өөр хүн | камерт бүртгэлтэй ажилтны оронд өөр хүн суусан хугацаа (камергүй бол «—») |
  | Баталгаажаагүй | амьд хүн (зураг, бичлэг биш) гэдэг нь батлагдаагүй хугацаа |

- **Мөр дээр давхар дарвал:** тухайн ажилтны өнөөдрийн дараах зүйлс харагдана:
  - урд талд байсан бүх програм, хуудас
  - хулгана байсан цонхнууд
  - нээлттэй байсан програмууд
  - түр зогсолтууд

**Бусад табууд**
- **Түр зогсолт:** энэ 7 хоногийн түр зогсолтууд: ажилтан, шалтгаан, эхэлсэн цаг, хугацаа, төлөв (Хүлээгдэж байна / Зөвшөөрсөн / Татгалзсан). Хүлээгдэж буй тоо табын нэр дээр «Түр зогсолт (2)» гэж гарна. Админ шалтгааныг уншаад «Зөвшөөрөх» дарвал түр зогссон хугацаа «Ажилласан»-д нэмэгдэж, «Гарсан»-аас хасагдана, өдрийн явцад `█` болно. «Татгалзах» дарвал «Гарсан» хэвээр үлдэнэ. Шийдвэрээ дараа нь өөрчилж болно, учир нь өдрийн файлд бичихгүй, самбарт л тооцдог. Хугацаа нь ажилтан «Хэмжилт эхлэх» (үргэлжлүүлэх) эсвэл «Дуусгах» дарахад тодорхой болно. Ажилтан өөрийн «Компьютерийн идэвх» табаас өнөөдрийн түр зогсолт, админы шийдвэрийг харна (шийдвэр гармагц дуу гарна). Ажилтны програм гэнэт хаагдвал (crash) зогсолт «дуусаагүй» үлдэж, ажилтан дахин хэмжилт эхлүүлэхэд сүүлд мэдээлэл ирсэн хүртэлх хугацаагаар хаагдана.
- **7 хоног:** энэ 7 хоногийн өдөр бүрийн ажилласан цаг (Да–Ня).
- **Хэрэглэгчид:** ажилтан бүртгэх (нэр, хэлтэс, дор хаяж 4 тэмдэгттэй код), устгах. Байгаа нэрийг дахин бүртгэвэл хэлтэс, код нь шинэчлэгдэнэ.
- **Хэлтэс:** хэлтэс бүрийн хүн, ажиллаж байгаа хүн, нийт ажилласан, дундаж бүтээмж.
- **Тохиргоо:** ажил эхлэх/дуусах цаг, хоцролтын хүлцэл, «Гарсан» гэж үзэх хугацаа, бүтээмжгүй програм/сайт.

## Төлөв гэж юу вэ

| Төлөв | Хэзээ |
|---|---|
| Ажиллаж байна | хэмжиж байгаа, гар эсвэл хулгана сүүлийн 60 секундэд хөдөлсөн, **мөн** камер ажилтныг өөрийг нь баталгаажуулсан («Амьд хүн ✓ · Бүртгэлтэй ажилтан ✓»). Камер ажиллахгүй (камергүй, кадр ирэхгүй) бол гар, хулганы хөдөлгөөн л хангалттай |
| Гарсан | гар, хулгана 60 секунд хөдлөөгүй, «Түр зогсоох» дарсан (товчлуурын доор шалтгаанаа бичнэ; админ зөвшөөрвөл тэр хугацаа ажилласанд тооцогдоно), эсвэл ажиллаж байгаа камер ажилтныг баталгаажуулаагүй (камерт өөр хүн, хүн алга, амьд хүн шалгаж байна / баталгаажаагүй, нүүр бүртгээгүй) |
| Офлайн | өнөөдөр ирсэн боловч 30 секунд мэдээлэл ирээгүй (програм хаагдсан, «Дуусгах» дарсан) |
| Ирээгүй | өнөөдөр нэг ч мэдээлэл ирээгүй |

**Таб таних хязгаар:** Windows цонхны гарчигт зөвхөн браузерын **идэвхтэй таб** гардаг. Тиймээс харж байгаа табын гарчиг бүртгэгдэнэ, ард нээлттэй байгаа табууд тоологдохгүй. Хуудасны хаяг (URL) биш, гарчгийг уншина.

## Камер хэрхэн шалгадаг вэ

Ажилтан админы серверт нэвтэрмэгц камер асна. Камерын хугацаа (ажилтан өөрөө, өөр хүн, хүн алга, баталгаажаагүй) зөвхөн хэмжилтийн үеэр тоологдож, 5 секунд тутам бусад өгөгдөлтэй хамт админ руу очно. Хэмжилтийн үеэр камерыг гараар хаах боломжгүй.

Нүүрийг зөвхөн илрүүлдэг биш, **таньдаг**: YuNet нүүр болон 5 цэгийг олж, SFace хэн болохыг тодорхойлно. Камер ажиллаж байхад ажилтныг өөрийг нь баталгаажуулаагүй секунд **«Ажилласан»-д тоологдохгүй**, «Гарсан» болно. Ингэснээр өөр хүн суусан, зураг тавьсан хугацаа ажилтны ажилласан хугацаанд орохгүй. Камер ажиллахгүй (камергүй компьютер, камер салсан, кадр ирэхгүй) үед ажилласан хугацааг гар, хулганы хөдөлгөөнөөр тооцох бөгөөд админы самбарт «● Ажиллаж байна (камергүй)» гэж харагдана. Өөр хүн рүү шилжсэнийг ойролцоогоор 1–2 секундийн дараа тогтооно, учир нь андуурлаас сэргийлэхийн тулд сүүлийн 5 танилтын олонхыг авдаг.

**Нүүр бүртгэх (нэг удаа):**
- Ажилтан «Нүүр бүртгэх» дараад дэлгэцийн зааврыг дагана.
- Нүүрний хээ админы компьютерт хадгалагдаж, «Хэрэглэгчид» табын «Нүүр» баганад «бүртгэсэн» гэж гарна.
- Ажилтан нүүрээ өөрөө дахин бүртгэж чадахгүй, шинэчлэх бол админ «Нүүр устгах» дарна.
- Анхны бүртгэлийг админы дэргэд хийх нь зөв. Эс бөгөөс ажилтан өөрийн оронд өөр хүний нүүрийг бүртгүүлж болно.

**Амьд хүн шалгалт:** заавар гарна: камер руу шууд харах, нүдээ 1 секунд аниад нээх, толгойгоо зааврын дагуу зүүн, баруун тийш эргүүлэх. Дараалал нь санамсаргүй бөгөөд чиглэлийг дэлгэц дээр сумаар харуулна.

| Шалгалт | Арга | Юуг илрүүлнэ |
|---|---|---|
| Нүдээ аних | Нээлттэй нүд илрүүлэгч (Haar) 2 нүдийг олохоо больж, дахин олох. Толгой хөдлөөгүй байх ёстой | **Зураг**: зураг нүдээ аньж чадахгүй |
| Толгой эргүүлэх | Нүд, амны 4 цэгийн хавтгайгаас хамар хажуу тийш зөрөх (параллакс). Дараалал санамсаргүй, буруу тийш эргүүлбэл шууд амжилтгүй | **Урьдчилан бичсэн бичлэг**: дарааллыг мэдэхгүй |
| Хэн сууж байна | Нүүрний 128 тооны хээ (SFace), бүртгэсэн хээтэй cosine ≥ 0.363. Секундэд ~3 удаа, сүүлийн 5-ын олонхоор | **Өөр хүн** ажилтны оронд суусан |

**Дахин шалгах үе:**
- Хүн 5 секундээс удаан алга болоод буцаж ирэхэд, мөн 10 минут тутам дахин шалгана. Энэ үед цонх урд гарч дуу гаргана.
- 25 секундэд зааврыг биелүүлэхгүй бол «баталгаажаагүй» гэж тоолж, 3 секундын дараа дахин шалгана.

**Хязгаарлалт:**
- Шууд видео дуудлагаар өөр хүн заавар дагаж байвал илрүүлэхгүй.
- Нүдний зай 40 пикселээс бага (хүн камераас 75 см орчмоос хол) бол шалгалт хийгдэхгүй.
- Нүдний шил хүчтэй гэрэл ойлгож байвал нүд илрүүлэлт алдаж болно.
- Камергүй компьютер дээр камерын баганууд «—» болж, ажилласан хугацааг зөвхөн гар, хулганы хөдөлгөөнөөр тооцно (энэ үед хэн сууж байгааг шалгах боломжгүй).

## Өгөгдөл

Өгөгдөл програмын файлын хажууд байх `data\` хавтаст хадгалагдана. Програмыг хаанаас, хэрхэн нээснээс үл хамаарна.
- `python main.py` ажиллуулбал: `main.py`-ийн хажууд
- `ProductivitySystem.exe` ажиллуулбал: `.exe`-ийн хажууд

Админы цонхны дээд талд өгөгдлийн хавтасны бүтэн зам харагдана. `.exe`-г өөр компьютерт хуулахдаа `data\` хавтсыг хамт хуулбал тэр компьютерийн админы нууц үг, ажилтнууд хамт очно. Хуулахгүй бол шинээр эхэлнэ.

| Файл | Агуулга |
|---|---|
| `employees.json` | Ажилтнууд: ID, нэр, хэлтэс, кодын хэш |
| `day-ОООО-СС-ӨӨ.json` | Өдөр бүрийн ажилтан тус бүрийн бичлэг: ажилласан, гарсан секунд, програм/хуудас тус бүрийн секунд, хулганы байршил, минут бүрийн төлөв, компьютерийн нэр, нээлттэй програмууд, камерын хураангуй (`camera`) |
| `pauses.json` | Түр зогсолт: ажилтан, шалтгаан, эхэлсэн цаг, үргэлжилсэн секунд, сүүлд мэдээлэл ирсэн цаг (`seen`), админы шийдвэр (`pending` / `approved` / `rejected`) |
| `settings.json` | Админы тохиргоо (анх «Хадгалах» дарахад үүснэ) |
| `admin.json` | Админы нууц үгийн SHA-256 хэш (git-д орохгүй) |
| `faces.json` | Нүүрний хээ: ажилтан бүрт 128 тоо (ажилтан нүүрээ бүртгүүлсний дараа үүснэ, git-д орохгүй) |

**Камерын хураангуй (`camera`):**
- `owner_seconds`: ажилтан өөрөө
- `other_seconds`: өөр хүн
- `no_face_seconds`: хүн алга
- `unverified_seconds`: амьд хүн шалгалт явагдаж байсан, амжилтгүй болсон, эсвэл нүүр бүртгээгүй
- `liveness_failures`: амжилтгүй шалгалтын тоо

**Загварууд** `models\` хавтаст байна. Хоёулаа [OpenCV Zoo](https://github.com/opencv/opencv_zoo)-оос авсан:
- `face_detection_yunet_2023mar.onnx`: нүүр + 5 цэг, MIT лиценз
- `face_recognition_sface_2021dec.onnx`: нүүрний хээ, Apache 2.0 лиценз

**Нууц үг, код:**
- Нууц үг, ажилтны код хоёулаа зөвхөн хэш хэлбэрээр хадгалагдана.
- Нууц үгээ мартвал `data\admin.json`-ийг устгаад шинэ нууц үгээр нэвтэрнэ.

**Хадгалагдах байдал:**
- Шууд төлөв (одоо юу хийж байгаа) зөвхөн админы програмын санах ойд байдаг, файлд бичигдэхгүй.
- Өгөгдөл `.exe` дотор биш тусдаа хавтаст байдаг тул програмыг хааж дахин нээхэд устахгүй.

## Ашигласан сан (12)

- **Python-д анхнаасаа байдаг:** `tkinter`, `json`, `os`, `sys` (програмын байршил), `time`, `random` (амьд хүн шалгалтын санамсаргүй дараалал), `ctypes` (Windows-оос цонх, хулгана, идэвх асуух), `socket` (сервер), `hashlib` (нууц үг)
- **Суулгах ёстой:** `opencv-python` (`cv2`), `numpy` (OpenCV-тэй хамт суудаг), `pyinstaller`

OpenCV-г **4.11 ба түүнээс шинэ, 5-аас доош** хувилбараар суулгана (`python -m pip install -U "opencv-python>=4.11,<5"`):
- 4.11-ээс хуучин хувилбар нүүр таних загварыг санах ойгоос уншиж чаддаггүй. Тэр үед програм файлын замаар уншина, гэхдээ програмын зам кирилл үсэгтэй бол камер ажиллахгүй.
- OpenCV 5-д нээлттэй нүд илрүүлэх Haar cascade байхгүй.

## Камер ажиллахгүй бол

Програм камерын 0, 1-р төхөөрөмжийг DSHOW, MSMF хоёр аргаар туршиж, бодитоор кадр өгсөн хослолыг сонгодог. Тэгээд ч ажиллахгүй бол камерын таб дээр шалтгааныг бичнэ. Шалгах зүйлс:

| Шинж тэмдэг | Шалтгаан, засах арга |
|---|---|
| «Камерын нүүр таних загвар ачаалж чадсангүй» | OpenCV хуучин: `python -m pip install -U "opencv-python>=4.11,<5"`. `models\` хавтас програмын хажууд байгаа эсэх |
| «Камер нээгдсэнгүй» | Zoom, Teams, «Камер» програм камерыг ашиглаж байна — хаана. Windows → Тохиргоо → Нууцлал ба аюулгүй байдал → Камер → «Камерт хандах», «Ширээний програмуудад камер ашиглахыг зөвшөөрөх» асаана. Device Manager дээр драйвер |
| «Камерын дүрс хар байна» | Камерын хаалт (shutter) хаалттай, F-товчоор (жишээ нь F8, F10) камер унтарсан, эсвэл Windows-ийн нууцлалын тохиргоо |

Камер ажиллахгүй үед ажилласан хугацааг гар, хулганы хөдөлгөөнөөр тооцож, админы самбарт «(камергүй)» гэж харуулна.

## Нууцлал

- **Камер:**
  - **Хэзээ ажиллах:** ажилтан админы серверт нэвтэрсэн үед асна. Хугацааг зөвхөн хэмжилт явагдаж байх үед тоолно. Хэмжилт хийгээгүй үед ажилтан «Камер хаах» дарж болно.
  - **Хадгалах зүйл:** зураг, бичлэг хадгалахгүй. Ажилтан «Нүүр бүртгэх» дарсан үед л нүүрний 128 тооны хээг админы компьютерийн `faces.json`-д хадгална. Үүнээс нүүрний зургийг сэргээх боломжгүй.
  - **Устгах:** ажилтныг эсвэл нүүрийг нь устгахад хээ нь хамт устна.
  - **Зөвшөөрөл:** энэ нь биометрийн өгөгдөл тул ажилтны зөвшөөрлийг авна.
- **Идэвх:** зөвхөн ажилтан «Хэмжилт эхлэх» дарсны дараа хэмжинэ. Энэ тухай бичиг ажилтны цонхон дээр харагдана.
  - **Бүртгэх зүйл:** урд талын болон хулганы доорх цонхны програм, гарчиг, нээлттэй програмууд, гар/хулгана хөдөлсөн эсэх.
  - **Анхааруулга:** хуудас, баримтын гарчигт хувийн мэдээлэл (жишээ нь имэйлийн гарчиг, чатын нэр) орж болохыг ажилтанд урьдчилан мэдэгдэнэ.
  - **Бүртгэхгүй зүйл:** товчлуурын даралт, бичсэн текст, хуудасны агуулга, дэлгэцийн зураг.
- **Үнэлгээ:** хугацаа, бүтээмжийн хувь нь ажлын чанарыг баталгаажуулахгүй, зөвхөн компьютер дээрх цагийг харуулна.
